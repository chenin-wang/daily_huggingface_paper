## 2.[Rethinking Critic Learning in PPO: Understanding and Mitigating Value Flattening](https://arxiv.org/pdf/2609.18708)
summary:**近端策略优化, 评论器学习, 价值平坦化, 稀疏近端策略优化, 大语言模型**  本文揭示并解决了大语言模型近端策略优化 (PPO) 评论器中存在的系统性失效模式“价值平坦化”问题，通过引入稀疏近端策略优化 (SP3O) 方法，即仅对每个响应中少数几个分离良好的状态应用价值损失，从而缓解了该问题并持续提升了策略性能。该研究旨在识别并缓解PPO评论器中“价值平坦化”这一被忽视的系统性失效模式，即通过多蒙特卡洛连续估计的状态值在中间状态急剧变化，而评论器预测值却相对平坦。研究引入了稀疏近端策略优化 (SP3O) 方法，通过仅在每个响应中对少数几个分离良好的状态应用价值损失来解决价值平坦化，该方法基于理论和实证分析，揭示价值平坦化与评论器损失函数中隐式方差惩罚以及时间相关状态的冗余更新有关，SP3O旨在同时缓解这两种效应。在Qwen3-Base上的实验表明，仅对每个响应监督三个状态的SP3O能有效缓解价值平坦化，SP3O在同域数学推理任务上相对于PPO提升了7.97个百分点，在域外推理任务上提升了7.33个百分点，持续改进了不同模型尺寸和评估套件下的学习策略。对于利用PPO训练大语言模型的AI工程师而言，这项工作识别并提供了PPO评论器中“价值平坦化”这一关键问题的解决方案，通过稀疏监督策略有效提升了策略性能和训练稳定性，具有重要的实践指导价值。

## 3.[Confidence Comes from Experience: Experiential Confidence Estimation from Reasoning to Agents](https://arxiv.org/pdf/2609.17708)
summary:**置信度估计**, **经验累积**, **大型语言模型**, **代理任务**, **校准误差** 本文提出XConf（经验置信度）方法，通过大型语言模型累积的过往经验，并结合Recall和Reflect阶段的机制，实现对模型输出置信度的可靠估计，为未来通用置信度估计提供新范式。 本文旨在解决现有置信度估计方法仅依赖当前推理过程的不足，为大型语言模型提供一种基于模型自身累积经验的、更可靠的校准置信度估计，以指导其输出的交付、升级和重试决策。 XConf将模型过往带分级的经验（包括任务、模型反思、初始置信度、结果和吸取的教训）存储为记录。当遇到新任务时，Recall阶段根据任务相似性和初始置信度检索相似历史经验并读取其成功率；Reflect阶段则将这些记录展示给模型，让其识别重复失败模式并重新校准置信度。该估计器与格式无关，无需logit访问或权重更新，仅需一次答案生成。 实验结果表明，XConf在九个基准测试中的24次比较中，有23次在判别能力（AUROC）上胜过或匹配了十样本自洽性方法，且校准误差（ECE）显著降低，生成成本仅为后者的十分之一。在代理任务中，通过放弃10%最低置信度的输出，交付成功率提高了8.7个百分点。 XConf为AI从业者提供了一种高效且可靠的模型置信度估计方法，尤其适用于推理、编码和交互式代理等复杂任务，能够显著提升大型语言模型部署的信任度和决策准确性。

## 5.[Agora: Git as Shared Memory for Collective AutoResearch](https://arxiv.org/pdf/2609.18094)
summary:**AutoResearch, 共享内存, Git, DAG, 语言模型权重迁移** AGORA系统通过将研究记录为基于Git的追加式有向无环图（DAG）作为代理共享内存，解决了自主研究代理在多代理设置中重复搜索而非更多发现的问题，并在一项语言模型权重迁移任务中实现了显著性能提升。 该研究旨在解决多个自主研究代理在AutoResearch任务中普遍存在的重复搜索问题，通过提供一种共享记忆机制来促进协同发现，并验证该机制在复杂AI任务中的有效性。 AGORA系统是一个基于Git的共享内存，将每个研究贡献记录为不可变提交，形成一个追加式有向无环图（DAG），每个提交的父边表示其构建基础；系统通过派生索引揭示研究前沿、被忽视的分支及验证状态，并采用多样性感知选择规则防止社区陷入单一文化。在一个为期近12天的实验中，13个语言模型代理在没有预设任务或中央规划器的情况下，协作解决了语言模型权重迁移问题，具体方法是将捐赠模型的下一词元统计信息压缩到目标模型的嵌入层和输出头，并通过稀疏编辑向注意力、前馈和状态空间模块添加短程上下文信号。 在实验中，代理社区发布了1,703项贡献，使评估器性能从3.39比特/字节提升至1.899比特/字节，缩小了与已训练GPT-2 124M模型差距的62%。其中，获胜方案的145个提交祖先跨越15个账户，且有165次独立复现均未失败。 AGORA系统为AI从业者提供了一个高效的协作研究框架，通过Git追踪不可变的研究成果和谱系，有效减少多代理AI系统中的重复工作，加速知识共享和验证过程，尤其在复杂模型初始化和权重迁移等任务中，能显著提升发现效率并确保研究的可复现性。

## 6.[ActionPiece: Rethinking Action Tokenization for Autoregressive Vision-Language-Action Models](https://arxiv.org/pdf/2609.18487)
summary:**动作分词器, 物理排序一致性, ActionPiece, 关系保真度** 本文针对自回归视觉-语言-动作（VLA）模型中动作分词器无法充分表征动作调整关系的问题，引入物理排序一致性（PRC）度量关系保真度，并提出ActionPiece方法通过联合表征学习和量化监督来保留物理动作关系，显著提升了策略训练和执行的成功率。  论文旨在解决现有动作分词器在压缩过程中，其点式重建误差指标（如MSE）无法充分反映不同演示之间动作调整的保真度，导致相似动作的上下文调整信息被削弱或扭曲的问题。为此，论文引入物理排序一致性（PRC）来衡量动作分词化在重建后保留局部物理距离排序的程度。  ActionPiece通过对表征学习和量化进行联合监督来保留物理动作关系，具体包括：物理排序保留（PRP）通过编码器和量化特征距离监督近远顺序；量化正则化（QR）将相同排序应用于码字分配分布，两者共同增强重建效果，生成用于标准自回归策略学习和执行的离散动作令牌。  在Qwen3-VL-4B策略训练环境下，ActionPiece在LIBERO上达到94.8%的成功率，在未见过的LIBERO-Plus上达到68.8%的成功率，并在SimplerEnv和VLA-Arena L0-L2上分别取得71.9%和51.5%的成功率。组件消融研究表明，PRP和QR联合显著提高了PRC和下游策略成功率。  对于AI从业者而言，这项研究表明在动作分词设计中，除了点式重建精度外，明确监督物理动作关系可以显著提高VLA模型在复杂和泛化场景下的机器人控制性能和成功率，为开发更鲁棒的动作表征提供了新的范式。

## 7.[VC-Attention: Value Smoothing and Softmax Casting for Low-bit Attention](https://arxiv.org/pdf/2609.15810)
summary:**VC-Attention**, **低位注意力**, **值平滑**, **Softmax Casting**, **扩散Transformer**  VC-Attention是一种免训练的低位注意力框架，通过结合值平滑（V-Smooth）和融合概率转换（ExpCast-FP8）来解决扩散Transformer视频生成中低位注意力的准确性和速度瓶颈。  该研究旨在解决扩散Transformer视频生成中低位注意力面临的两个主要挑战：一是因值异常值导致的量化精度损失，二是Softmax操作中高精度指数计算造成的速度瓶颈。  VC-Attention的核心方法是结合值平滑（V-Smooth）和融合概率转换（ExpCast-FP8），其中V-Smooth通过轻量级在线聚类重排序值token、对减去块均值后的残差进行量化并从在线Softmax的行和中恢复均值，ExpCast-FP8则通过一次融合乘加操作将对数域分数直接映射到E4M3概率代码，从而消除了FP32指数运算和格式转换。  在Wan2.2、LongCat-Video、HunyuanVideo-1.5和MiniMax-H3等模型上，VC-Attention相较于BF16 FlashAttention-4，在数据中心Blackwell和Hopper卡上将注意力内核速度提升了1.46-1.59倍，在工作站卡上提升了2.3-3.6倍，端到端视频生成速度提升了1.13-1.19倍和1.36-1.70倍，并提高了低位基线的视频保真度。  VC-Attention为AI从业者提供了一个无需训练的低位注意力框架，有效提高了扩散Transformer视频生成的效率和保真度，这对于在数据中心和工作站GPU上部署高性能视频生成模型具有重要意义，因为它显著降低了计算成本并加速了推理过程，且无需额外的模型再训练。
