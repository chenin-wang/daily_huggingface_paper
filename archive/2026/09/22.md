## 0.[EvoOntology: A Self-Evolving Ontology Layer for Data Agents](https://arxiv.org/pdf/2609.15779)
summary:**数据代理, 本体层, 自进化, 异构数据, MCP服务器**  EvoOntology引入了一个自进化的数据代理本体层，其将本体封装为包含模式层、内容层和工具层的MCP服务器，使代理能够在运行时主动查询和交互本体，并通过构建器代理进行自主本体构建和自进化循环进行持续优化，从而有效弥合了代理与异构数据之间的鸿沟，实现了更高效的交互。  该研究旨在解决数据代理在处理异构数据（如表格、文件、数据库）时面临的代理-数据鸿沟挑战，即代理只能通过通用工具访问数据，而无法先验地了解其结构和内容，导致现有方法难以扩展并适应不同的代理行为。  EvoOntology通过一个自进化的本体层来桥接代理与数据。该本体层作为MCP服务器，包含模式层（定义对象类型和引用规则）、内容层（存储领域知识和数据映射）和工具层（暴露可执行接口）。首先，一个构建器代理通过向底层数据源发出探测查询并进行数据接地，构建初始本体。随后，一个自进化循环根据代理的交互轨迹持续优化本体，通过归因分析识别本体缺陷，提出针对性改进，并仅在通过骨干网络条件下的配对评估后接受这些改进。  实验结果表明，EvoOntology在三个广泛采用的数据代理基准测试上，使用四种LLM骨干网络进行评估，始终优于强基线和现有语义层方法。例如，在DDR-Bench基准测试中，EvoOntology使Trajectory-Wise准确率平均提高了17.8个百分点。  EvoOntology为AI从业者提供了一种有效且可扩展的解决方案，通过自进化本体层使数据代理能够更深入地理解异构数据，从而提升自动化数据分析和决策的效率与准确性，特别是在处理大规模、多样化数据源的复杂任务时。

## 1.[CodeMidas: Scaling Agentic Coding RL Environments from Code Itself](https://arxiv.org/pdf/2609.22068)
summary:**核心关键词**: 智能编程代理, 强化学习环境, 源代码, Agentic pipeline, CodeMidas  CodeMidas提出了一种Agentic pipeline，利用现有代码库中的实现功能，仅以源代码作为任务特定输入，构建可执行的强化学习环境，旨在解决现有方法对开发工件的依赖限制，从而扩展RL环境并提升编程代理的性能。本研究旨在解决训练高效编程代理的强化学习环境扩展性问题，特别是现有方法依赖于开发工件（如issues和commits）的局限性。CodeMidas采用Agentic pipeline，仅以源代码作为任务特定输入，自动化RL环境构建。该方法通过代理探索现有功能以制定行为规范，基于原始代码执行构建测试，并利用执行检查和重复解决方案回滚来验证和筛选候选任务。最终数据集包含5,545个训练任务，覆盖23种编程语言和15个技术领域。在此任务集上，训练MiMo-V2.5结合GRPO算法在DeepSWE基准测试中提升11.7%，ProgramBench提升17%，以及Terminal-Bench v2.1提升8.5%，并在所有五个多样化基准测试中均有性能改善。这些结果确立了源代码作为构建RL环境的可扩展基础，对于开发和改进能处理多样化软件任务的编程代理具有重要价值，为AI/ML/软件工程师提供了提升智能编程系统能力的途径。

## 2.[Grounded Skill Synthesis from Code at Scale for Agentic Intelligence](https://arxiv.org/pdf/2609.05571)
summary:**Agentic Intelligence**, **Skill Synthesis**, **Code2Skill**, **CodeSkillBank**, **Procedural Knowledge** 该研究提出Code2Skill自动化流水线，通过将代码单元转化为可执行的原子操作、复合工作流和重复模式技能记录，并进行源体盲重建与源感知比较验证，从而构建了一个可扩展的代码派生技能库CodeSkillBank，旨在为智能体提供可转移且可验证的程序知识。 该论文旨在解决现有技能合成方法（基于轨迹或文档）在可扩展性、可执行证据和验证方面的局限性，并探索源代码作为一种新的、可靠的知识来源，以规模化地为智能体系统合成可重用、可验证的程序技能。 Code2Skill是一种全自动流水线，首先从GitHub仓库中筛选代码单元，将其转换为锚定实现的原子操作、复合工作流和重复模式技能记录，这些记录包含工作流、边界、溯源和源证据元数据。然后，通过源体盲重建（即大型语言模型仅依据合成技能重建实现代码）和源感知比较（将重建代码与原始代码进行比较）来验证这些技能记录的正确性和完整性，从而确保其可落地性。 应用Code2Skill到19,769个GitHub仓库，生成了包含1,006,822条已接受记录的CodeSkillBank。在72项跨9种模型设置和8个基准的评估中，结合CodeSkillBank技能的模型比基线平均性能提升11.7%，并在57个案例中表现优异。此外，从AI生成代码合成的技能通过率为93.50%，与人工编写代码派生技能的93.00%相比，性能相当。 对于AI从业者，Code2Skill提供了一种新的范式，可以在智能体积累足够交互经验之前，将软件仓库中内嵌的人类程序知识转化为可落地、可验证且可转移的技能，从而显著提升智能体系统的性能和可扩展性，尤其是在软件工程和系统交互等任务中，并为未来AI生成代码的技能扩展提供了可行性。

## 3.[RecreationWorld: Scalable and Verifiable Environments for Hybrid Computer-Use Agents](https://arxiv.org/pdf/2609.22000)
summary:**Core Keywords**: 混合式计算机使用代理, RecreationWorld, RecreationBench, GUI控制, 代码生成 本研究引入了RecreationWorld，一个围绕“重现”概念构建的五平台框架，旨在通过代理自主探索界面、实现软件并视觉验证其产物，从而在可复现环境中培养混合式计算机使用代理（CUA）能力，并以运行中的参考应用作为隐藏行为测试的预言机，提供执行驱动的奖励。 该论文旨在研究混合式计算机使用代理（CUA）如何自主决定何时探索界面、何时实现软件以及何时运行和视觉验证其产物，以解决真实数字工作中图形界面操作与代码/命令行软件开发之间交错进行的挑战。 研究核心方法是RecreationWorld框架，它在Ubuntu、macOS、Windows、Android和Web五大平台上提供可复现环境及统一的GUI控制和编码工具，代理需根据运行中的参考应用行为，在无预设工作流的情况下，构建一个忠实的实现；并通过参考驱动的程序化与视觉断言，在多个交互深度上覆盖动作条件结果，进行验证与评分。 实验结果表明，经过训练的模型在五项域外编码和混合计算机使用基准测试中表现有所提升。在RecreationBench上，GPT-6 Astra总体得分最高达58.1%，但在所有程序化测试中仅通过了2.8%的任务；代理重现静态界面结构比重现交互和计算输出更可靠，且生成的应用比参考应用更小、更单一。 RecreationWorld为AI从业者提供了一个可扩展且可验证的框架，用于训练和评估能够融合GUI操作与代码开发的长周期混合式AI代理，其基于执行的奖励机制和对开放源应用的利用，有助于促进AI代理在更真实、多模态工作环境中的泛化能力和自我改进。

## 4.[IntBMoE: Integrating Block-Level Conditioning into Expert Composition for Full-Participation Mixture-of-Experts](https://arxiv.org/pdf/2609.21346)
summary:**IntBMoE**, **混合专家模型 (MoE)**, **块级条件 (Block-Level Conditioning)**, **全参与 (Full-Participation)**, **双路径残差门控 (DPRG)** 该研究提出了IntBMoE，一种块级条件化的混合专家模型，通过将密集专家组合与稀疏块执行配对，有效解耦了专家参与度、计算执行成本和参数物化成本，并在多模态任务中实现了性能提升和实际部署价值。 该论文旨在解决现有混合专家模型（MoE）设计中，专家参与度、计算执行成本和参数物化成本之间无法独立设置、存在耦合导致性能权衡的问题。 IntBMoE通过以下方式实现解耦：使用小型学习到的码本定义块，每个内部层中的轻量级超网络将该层池中的所有专家基础合并为一个组合专家，从而实现全参与；路由器仅将每个token发送到少数块以保持稀疏执行；码本固定了块的数量，从而限制了参数物化。此外，模型引入了双路径残差门控（DPRG）机制，通过乘法门控进一步耦合两条独立组合的路径。 实验结果表明，IntBMoE在图像分类任务上表现出优于现有稀疏和密集MoE基线的持续改进。在AMap的生成推荐系统中，IntBMoE已全面部署，在60毫秒延迟预算下实现了2.4%的UVCTR相对增益。 IntBMoE通过解决MoE中参与度、执行和物化成本的耦合问题，为AI工程师和研究人员提供了一种更高效、更灵活的模型设计范式，使其能够在保证模型性能的同时，更好地控制计算和内存资源，特别是在低延迟、大规模在线推荐系统等实际应用中展现出显著的商业价值和技术可行性。

## 5.[OmniVChat: Synthesizing, Benchmarking, and Training for Native Audio-Visual Dialogue](https://arxiv.org/pdf/2609.21465)

## 6.[Paint-Anything: Unified Any-Color Control for Image Generation and Editing](https://arxiv.org/pdf/2609.20816)
summary:**统一色彩控制**, **图像生成与编辑**, **十六进制提示界面**, **纯色锚点**, **ACBench**  Paint-Anything 提出了一个统一的十六进制提示界面，用于通过对象级颜色监督实现图像生成和编辑的任意颜色控制能力，并通过引入 Paint-500K 数据集、纯色锚点和 ACBench 基准测试，在FLUX.2-4B模型上显著提升了对象级十六进制颜色保真度。该研究旨在解决专业设计中对图像生成和编辑进行任意颜色控制的需求，即能够以任意24位十六进制值指定对象的颜色，克服现有方法对专用颜色表示或推理程序的依赖问题。Paint-Anything 学习了一个共享的十六进制提示界面，通过对象级颜色监督进行生成和编辑。其核心方法包括开发一个数据管道构建 Paint-500K 数据集，该数据集通过对象接地、感知颜色标注和编辑对合成从真实图像中提取数据；并引入纯色锚点，其像素与配对的十六进制值精确匹配，在训练时仅在高噪声时间步长激活，以补充真实图像的近似颜色标签，确保十六进制到RGB的清晰映射。在 FLUX.2-4B 模型上，Paint-Anything 相对于基线模型，将 ACBench-T2I（文本到图像）分数提高了85.3%，ACBench-Edit（图像编辑）分数提高了28.3%，并取得了最高的平均 CompColor 分数。对于AI从业者而言，Paint-Anything 提供了一个统一且高效的解决方案，通过直接使用十六进制值作为提示，实现了对图像颜色在生成和编辑任务中的精确控制，这简化了工作流程并为品牌设计、产品定制等需要严格颜色规格的应用场景提供了强大的能力。

## 7.[Designer-RSI: Evolving Procedural Memory from User Traffic for Agentic Graphic Design](https://arxiv.org/pdf/2609.22086)
summary:**代理式平面设计**, **程序记忆**, **持续适应**, **用户流量**, **重放门** 本文提出一个持续适应框架，使冻结的基础模型通过外部自然语言技能程序记忆在专业图形设计软件中运行，并通过用户流量积累和完善可重用设计程序，从而在缺乏可靠程序性预言机的长周期代理式平面设计任务中实现持续适应。  该研究旨在解决专业图形设计这种成果难以通过程序精确验证的长周期代理任务中，如何通过用户流量对智能体进行持续适应和性能提升的问题。  核心技术方法是一个包含冻结前沿模型和外部程序记忆库的持续适应框架。该框架通过两种机制演化记忆：**拓宽**（widening）机制通过获取未覆盖的重复子任务程序来扩展能力；**深化**（deepening）机制通过对比成功和失败执行来修订现有程序。所有提议的更改都需通过一个**匹配重放门**（matched replay gate）进行验证，确保修复失败的同时不损害已有的成功表现。  经过五轮迭代（涉及1,406个用户简报和1,869条自动评分轨迹），程序记忆库从76个技能增长到139个，将Claude-Sonnet-4在GenEval2上的执行成功率从72.7%提高到99.3%（生成质量提升11.99个百分点）。在200个保留的用户流量简报上，拓宽和深化机制结合使用时，代理对无技能代理的胜率为58.5%（p = 0.025），显著高于单独使用（49.4% / 48.6%）。  对于人工智能从业者而言，程序记忆为在嘈杂、不可验证反馈下实现智能体持续适应提供了一条实用途径，使得智能体可以在不更新基础模型参数的情况下，通过外部上下文积累经验并提升在复杂长周期任务中的性能。

## 8.[OmniVBench: A Benchmark and Large-Scale Dataset for Omni Reference-to-Video Generation](https://arxiv.org/pdf/2609.22069)

## 20.[TeleAntiFraud 2.0: A Refreshable, Profile-Grounded, and Audio-Based Benchmark for Telecom Fraud Detection](https://arxiv.org/pdf/2609.18748)
summary:**电信诈骗检测, 音频基准测试, 混合树生成, 抗欺诈基准, 近域负例** 本文提出了TeleAntiFraud 2.0，一个通过混合树生成管道构建并采用月度冻结评估协议的音频电信诈骗检测基准，旨在解决现有基准无法纳入新诈骗模式和区分近域合法通话的问题，并揭示了模型在真实混淆条件下存在近域负例区分困难和预测崩溃等挑战。 该研究旨在解决音频电信诈骗检测基准在两个关键方面的不足：一是如何持续纳入新诈骗模式而无需覆盖现有测试集；二是如何使模型能够区分诈骗通话与听起来相似的合法近域通话，而非仅仅依赖话题分离的负例。 本文提出了TeleAntiFraud 2.0基准，采用“混合树抗欺诈生成管道”构建。该管道将在线诈骗案例摘要转化为基于配置文件的情景，通过混合树生成扩展为诈骗和非诈骗对话路径，这些路径在共享语境下实现，最终渲染为角色匹配的语音对话，并以月度冻结评估集的形式发布，包含音频、标签、提示、清单和溯源记录。 受控文本实验表明，三个分类器在针对不相关或普通负例进行评估时能达到完美的宏平均F1分数，但当面对近域相似的负例时，F1分数显著下降至0.65-0.68。此外，全集音频和ASR+LLM评估揭示了模型存在类先验捷径、预测崩溃和对快照敏感性等问题。 这项研究为AI从业者提供了更具挑战性和可审计性的音频电信诈骗检测基准，强调了在评估电信诈骗模型时，近域负例的构建和“崩溃感知报告”（collapse-aware reporting）是至关重要的要求，有助于开发更鲁棒的防欺诈系统，避免模型依赖容易的捷径。
