## 0.[ERNIE 5.0 Technical Report](https://arxiv.org/pdf/2602.04705)
summary:**ERNIE 5.0, 多模态理解与生成, 自回归基础模型, 超稀疏MoE, 弹性训练**  ERNIE 5.0是一个原生自回归基础模型，旨在通过统一的next-group-of-tokens预测目标，采用基于超稀疏MoE架构和模态无关专家路由的核心方法，并引入弹性训练范式，解决大规模部署挑战，实现统一的多模态理解与生成。该研究旨在解决在统一自回归范式下，如何实现对文本、图像、视频和音频等所有模态的原生支持，同时保持强大的单模态能力，并有效扩展模型和数据规模，以及应对多样资源限制下大规模部署的实际问题。其核心技术方法是构建一个统一的自回归骨干网络，将所有模态从头开始训练，并结合模态无关专家路由的超稀疏MoE架构；同时，提出一种新颖的弹性训练范式，在单次预训练中学习不同深度、专家容量和路由稀疏度的子模型族，并系统性地解决强化学习在统一基础模型中的扩展挑战。广泛实验表明，ERNIE 5.0在多模态上实现了强大且均衡的性能，例如在推理时将路由top-k减少至25%时，解码速度提升超过15%且准确率损失微小，并在仅激活53.7%参数和总参数35.8%的情况下，通过弹性训练仍能保持接近完整的性能。对于AI从业者而言，这些发现意味着ERNIE 5.0的弹性训练范式能够在性能、模型大小和推理延迟之间进行灵活权衡，有效应对内存或时间受限场景下的部署需求，同时为未来基础模型的架构设计提供了深刻的工程指导。

## 1.[FASA: Frequency-aware Sparse Attention](https://arxiv.org/pdf/2602.03152)
summary:**LLM KV Cache, 稀疏注意力, RoPE, 频率块 (FCs), 查询感知**  该研究提出了FASA框架，通过利用RoPE中频率块的功能稀疏性，实现查询感知的token逐出，旨在解决大型语言模型KV缓存的内存瓶颈，并在长上下文任务中超越现有基线，达到接近Oracle的准确性。 该论文旨在解决大型语言模型（LLMs）部署时，Key Value (KV) 缓存因处理长输入而产生的内存和带宽瓶颈问题，通过动态预测token重要性来实现查询感知的token逐出。 FASA基于对RoPE中频率块（FCs）功能稀疏性的发现，提出了一种两阶段方法：首先通过“token重要性预测器”（TIP）利用一小部分“主导”FCs识别关键token；然后，“聚焦注意力计算”（FAC）仅在这些被剪枝的关键token子集上执行全维度注意力计算，从而显著降低内存带宽和计算成本。 在LongBench-V1数据集上，FASA在仅保留256个token的情况下，性能几乎达到完整KV缓存的100%。在AIME24数据集上，FASA仅使用18.9%的缓存实现了2.56倍的加速。 对于AI工程师而言，FASA提供了一种实用的、高效的LLM长上下文推理解决方案，显著降低了KV缓存的内存占用和计算开销，使得在资源受限的环境下部署和运行大型模型成为可能，提升了模型的经济性和可及性。

## 3.[Training Data Efficiency in Multimodal Process Reward Models](https://arxiv.org/pdf/2602.04145)
summary:**多模态过程奖励模型, 数据效率, Balanced-Information Score, Monte Carlo标注**  本研究通过解决多模态过程奖励模型（MPRMs）训练数据效率问题，揭示现有MC标注数据存在冗余，并提出Balanced-Information Score（BIS）数据选择机制，显著降低训练成本同时保持甚至超越全数据性能。  本论文旨在解决多模态过程奖励模型（MPRMs）训练中昂贵的Monte Carlo（MC）标注语料导致的数据效率低下问题。  研究通过理论框架分析，指出信息梯度更新依赖于正/负步骤的标签混合比例和正步骤的标签可靠性（平均MC分数）。基于此，提出Balanced-Information Score（BIS），无需额外成本即可根据现有MC信号在rollout级别上优先选择兼顾标签混合和可靠性的数据。  实验结果表明，在VisualProcessBench数据集上使用InternVL2.5-8B和Qwen2.5-VL-7B两个骨干模型，BIS选择的子集在仅使用10%训练数据的情况下，即可达到全数据性能，并相对于随机采样提高了4.1%的性能。  对于AI从业者而言，本研究提供了一种实用的数据选择方法，能够在大幅减少MPRM训练计算成本（例如95.5%的更新次数）的同时，不牺牲模型性能，这对于开发和部署高效的多模态大型语言模型具有重要意义。

## 4.[OmniSIFT: Modality-Asymmetric Token Compression for Efficient Omni-modal Large Language Models](https://arxiv.org/pdf/2602.04804)

## 5.[HySparse: A Hybrid Sparse Attention Architecture with Oracle Token Selection and KV Cache Sharing](https://arxiv.org/pdf/2602.03560)
summary:**HySparse**, **混合稀疏注意力**, **Oracle令牌选择**, **KV缓存共享**  本文提出HySparse，一种混合稀疏注意力架构，通过从前一个全注意力层战略性地获取稀疏层的令牌选择和KV缓存，解决了现有稀疏注意力方法中代理令牌选择的复杂性和潜在次优性能，以及现有设计在减少计算的同时未能有效节省KV缓存的两个根本限制，从而在7B稠密和80B MoE模型上实现了计算和内存的显著减少，并持续超越全注意力及混合SWA基线，特别是在80B MoE模型中将KV缓存存储减少了近10倍。  该研究旨在解决现有稀疏注意力方法中依赖代理预测令牌重要性所引入的额外复杂性和潜在次优性能，以及现有设计在减少计算的同时未能有效节省KV缓存的两个根本限制。  其核心方法是将每个全注意力层与多个稀疏注意力层交错，稀疏层的令牌选择直接从前一个全注意力层获取作为“精确预言机”。同时，稀疏注意力层重用前一个全注意力层的KV缓存，并结合了拥有独立轻量级KV缓存的滑动窗口注意力（SWA）分支，最终通过Sigmoid门融合输出。  HySparse在7B稠密和80B MoE模型上进行了评估，在所有设置中均持续优于全注意力及混合SWA基线。特别是在80B MoE模型（总49层，仅5层全注意力）中，HySparse在实现显著性能提升的同时，将KV缓存存储减少了近10倍。  对于AI从业者而言，HySparse通过优化令牌选择和KV缓存管理，大幅降低了大型语言模型的计算和内存成本，提供了一种高效且准确的长上下文建模解决方案，使得在不牺牲模型能力的前提下，全注意力层的数量可以显著减少。

## 9.[TIDE: Trajectory-based Diagnostic Evaluation of Test-Time Improvement in LLM Agents](https://arxiv.org/pdf/2602.02196)
summary:**TIDE**, **LLM Agents**, **Test-Time Improvement (TTI)**, **Diagnostic Evaluation**, **Trajectory-based**  TIDE是一个智能体和环境无关的框架，通过分解LLM智能体在测试时改进（TTI）的三个维度——任务优化效率、错误行为适应和工作记忆效用，来诊断和理解其迭代交互过程。  该研究旨在解决LLM智能体测试时改进（TTI）的成功或失败机制不明确以及现有评估指标在任务优化效率、错误行为适应和工作记忆效用方面存在不足的问题。  论文提出了“测试时改进诊断评估（TIDE）”框架，它是一个轻量级、智能体和环境无关的工具，通过三个互补指标（AUV、LR、MI）来量化TTI的动态：AUV衡量任务完成的整体时间动态，LR区分循环停滞与行为适应，MI评估累积记忆的效用。  广泛实验表明，TIDE揭示提升智能体性能不仅需增强内部推理，更需优化智能体与环境的交互动态。例如，在AlfWorld中，DeepSeek-V3.2和Gemini 2.5 Pro的最终成功率均为0.807，但Gemini 2.5 Pro的AUV为0.629，高于DeepSeek-V3.2的0.590，体现了早期TTI效率的差异。此外，Qwen3-4B-Instruct在FrozenLake环境中记录的循环率（LR）为32.0%，表明其在面对错误时易陷入递归失败行为。  对于AI从业者，这项工作强调在LLM智能体设计中，应将重点从评估静态能力转向诊断和优化智能体动态，即关注如何高效、适应性强且有效地通过交互进行改进。

## 10.[Residual Context Diffusion Language Models](https://arxiv.org/pdf/2601.22954)

summary:**代理RAG**, **分层检索接口**, **大语言模型**, **工具使用**, **上下文效率** 本文介绍了A-RAG，一个代理RAG框架，通过向模型直接暴露分层检索接口，包括关键词搜索、语义搜索和块读取三种工具，使模型能够跨多粒度自适应搜索和检索信息，从而在多个开放域问答基准上持续超越现有方法，并以相当或更低的检索token量有效利用模型能力并动态适应不同的RAG任务。该研究旨在解决现有RAG系统未能有效利用前沿大语言模型的强大推理和长周期工具使用能力，无法让模型参与检索决策，阻碍其随模型改进而高效扩展的问题。A-RAG通过构建分层索引（包含句子级的密集向量表示和块级的完整内容）并提供分层检索接口实现代理能力，这些接口包括：`keyword_search`用于精确词汇匹配，`semantic_search`用于语义相似性检索，以及`chunk_read`用于获取完整块内容，并采用ReAct-like代理循环，使模型能够迭代进行推理和工具调用。实验表明，在GPT-5-mini作为骨干LLM时，A-RAG (Full)在MuSiQue数据集上实现了74.1%的LLM评估准确率，显著优于Naive RAG的52.8%和LinearRAG的62.4%，并在所有基准测试中均取得优异表现，同时检索的token数量与传统RAG方法相当或更少。A-RAG框架为AI从业者提供了提高RAG系统性能和效率的新范式，通过赋予LLM在检索决策上的更大自主权，实现了动态适应任务需求和更优的上下文效率，推动了RAG系统向更智能、更具可扩展性的代理化方向发展。
