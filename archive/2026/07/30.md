## 0.[HiFi-UMI: Learning Deployable Manipulation Policies from High-Fidelity UMI Data Alone](https://arxiv.org/pdf/2607.25895)
summary:**高保真UMI数据**, **零机器人后训练**, **可部署操作策略**, **视觉-语言-动作模型**, **世界-动作模型** 本文研究如何仅利用高保真机器人无关的通用操作界面（UMI）数据学习可部署的操作策略，通过共同设计硬件和软件实现高精度数据捕获，从而在实际机器人上实现零机器人后训练，并与领域内遥操作基线性能匹敌。  本研究旨在探讨是否可以通过提升机器人无关UMI数据的保真度，而非缩小真实机器人数据比例，来完全消除后训练阶段对真实机器人数据的依赖，从而实现可部署的操作策略学习。  核心方法是构建了HiFi-UMI便携式数据生产系统，通过硬件和软件协同设计，解决了轨迹精度、抓手间相对姿态、同步性和视野等UMI数据捕获挑战。具体技术包括头戴式离线立体惯性SLAM、原生抓手间相对姿态测量、共享微秒级GPIO硬件触发以及每只手配备两个覆盖约200°的广角摄像头，实现了3毫米工作空间局部末端执行器精度，无需外部追踪基础设施。  实验结果表明，仅通过HiFi-UMI数据进行后训练的策略在实际机器人上部署时，与在评估场景中收集的领域内遥操作基线表现相当，在StarVLA-QwenPI、OpenPI-π0.5和LingBot-VA三个骨干网络上成功率差异分别为-2.5、+3.1和-0.6个百分点；其中最强策略在精确插入任务中达到85%的成功率。此外，使用相同语料库进行4000小时预训练可将十个未见任务的动作误差降低41%，并使StarVLA-QwenPI上的真实机器人成功率提高18.1个百分点。  对于AI从业者而言，本研究的核心价值在于证实了高保真、机器人无关的UMI数据足以支持可部署的操作策略学习，从而无需昂贵的真实机器人遥操作数据作为后训练的“锚点”。这意味着AI/ML工程师和数据科学家可以利用更具成本效益和可扩展性的UMI数据收集方案，来开发和部署高性能机器人操作策略，加速机器人学习领域的发展。

## 1.[A New Role for Relevance: Guiding Corpus Interaction in Agentic Search](https://arxiv.org/pdf/2607.24223)
summary:**Agentic Search**, **Corpus Interaction**, **Relevance Guidance**, **RipGrep**, **RARG** 本文提出了一种名为RARG的相关性感知RipGrep搜索代理，通过将相关性作为语料库交互的执行先验，提供粗粒度到细粒度的指导，从而在复杂问答和推理密集型检索任务中提高了代理的准确性和搜索效率。该研究旨在解决现有检索代理和直接语料库交互在复杂问答和推理任务中无法有效利用相关性来精确定位、组合和验证证据，导致搜索效率低、收敛慢的问题。RARG将相关性转化为语料库交互的执行先验，通过排序文档以进行ripgrep遍历、使用查询相关段落初始化搜索入口点，并重新排序grep匹配结果，以浮现文档级别排序可能掩盖的信息丰富的摘录，提供多层次指导。实验结果表明，RARG在挑战性浏览问答和推理密集型检索任务中，相对于传统检索代理和直接交互代理，显著提升了准确性-效率前沿，例如在100K文档的BrowseComp-Plus语料库上，RARG++实现了84%的准确率，而RISE和DCI均为78%。RARG的发现对AI从业者意味着，通过将相关性转化为主动的执行先验而非被动的过滤机制，可以显著提高代理在处理复杂信息需求时的搜索效率和结果可靠性，尤其在需要精确定位和验证证据的场景下。

## 2.[CodeNib: A Multi-View Data System for Serving Repository Context to Coding Agents](https://arxiv.org/pdf/2607.25431)
summary:**多视图数据系统**, **代码代理**, **仓库上下文**, **增量维护**, **上下文服务** CodeNib 提出了一个多视图数据系统，通过构建和维护可重用的词法、密集和结构化视图，将输出映射到仓库相对源范围，并通过单一运行时提供服务，从而解决了代码代理在演化仓库中因索引不连贯、语言服务器和任务局部历史导致的重复发现和模糊生命周期成本问题。 该研究旨在解决代码代理在处理演化仓库时，因索引不连贯、语言服务器和任务局部历史记录分离，导致重复发现和生命周期成本模糊的问题。 CodeNib 的核心方法是为每个仓库提交构建可重用的词法、密集和结构化多视图数据系统，将输出映射到仓库相对源范围，并通过单一运行时提供排名搜索、符号导航和有界上下文服务，同时在编辑过程中维护所选视图。 实验结果表明，在输出匹配独立重建时，图和向量更新的中位速度分别提升了8.7倍和25.4倍。此外，对于匹配标准化实时服务器位置的静态导航子集（占1,000个请求的63%），CodeNib 的中位请求延迟与实时服务器之比为4.7倍。在五个模型中，所选上下文策略能够将轨迹令牌减少50%至87%，相比传统的grep/read方式，显著降低了令牌消耗。 这些发现对于AI从业者具有重要意义，表明通过CodeNib的多视图数据系统，可以高效、一致地为代码代理提供仓库上下文，显著降低了维护成本和令牌消耗，从而提升了AI代码代理的开发效率和应用性能。

## 3.[ReDesign: Recovering Editable Design Structures from Images via Agentic Decomposition](https://arxiv.org/pdf/2607.25565)
summary:**智能体框架, 可编辑设计结构, 栅格图像重建, 渐进式验证, Figma基准测试** ReDesign提出了一个智能体框架，通过代理式分解和渐进式验证，从栅格图像中恢复可编辑的设计结构，在布局、颜色和文本编辑方面实现了高视觉保真度和最高可编辑性，超越了现有基线方法。该研究旨在解决现代设计工作流程中从栅格图像恢复可编辑设计文件（如Figma或Adobe Illustrator文件）的瓶颈问题，这需要恢复多模态属性，包括排版、矢量几何、颜色、分组和图层顺序。核心方法是ReDesign智能体框架，它将重建任务视为结构化树扩展，VLM控制器选择并组合专用工具（如文本提取、多层分解、连接组件标记、检测与分割和矢量化）来逐步细化层级结构。每次父子节点扩展时，都会进行渐进式验证，提供接受、剪枝或重试反馈，以防止错误累积和大规模重新运行。实验通过Figma编辑重放基准评估了视觉保真度和可编辑性，该基准包含909个Figma文件和14,796条编辑指令。结果表明，ReDesign在布局、颜色和文本编辑方面均实现了最高的编辑能力，Figma数据集上布局F1分数达到0.535，优于所有分层分解基线和串行工具使用管线。对于AI开发者而言，ReDesign证明了在智能体系统中施加结构性约束（如树状分解和渐进式验证）可以同时提高可控性、准确性和效率，使故障局部化并可修复，并实现可预测和可扩展的执行，例如相比串行工具执行速度提升7.1倍。

## 4.[Pass the Baton: Trajectory-Relayed On-Policy Distillation](https://arxiv.org/pdf/2607.26057)
summary:**策略蒸馏**, **前缀错误**, **中继在策略蒸馏**, **师生延续不对称**, **轨迹中继** 本文提出中继在策略蒸馏（Relay-OPD），通过利用师生延续不对称性触发教师干预，解决标准在策略蒸馏中的前缀错误问题，从而提高学生模型在推理任务上的性能和训练效率。 本文旨在解决在策略蒸馏中学生模型因早期推理方向错误而导致后续生成偏离、监督不可靠和计算浪费的前缀错误问题。 中继在策略蒸馏（Relay-OPD）识别出失败前缀上的师生延续不对称性（教师倾向于重定向而学生倾向于沿原方向继续），并将其转化为免标签的切换触发器。在训练期间，它通过在检测到的触发点让教师短暂接管生成“教师支路”来构建中继轨迹，之后学生恢复生成并在由此产生的轨迹上进行优化，同时通过限制中继预算来聚焦早期关键位置的干预。 在八个数学推理基准上，使用Qwen3-4B教师模型和Qwen3-1.7B学生模型，中继在策略蒸馏（Relay-OPD）的平均准确率比标准在策略蒸馏高出5.73%，比最强的基线FastOPD高出1.49%，且在0.6B学生模型上亦有持续提升。此外，训练轨迹长度减少了50%以上。 对于AI从业者而言，中继在策略蒸馏通过实现在线有针对性的干预，纠正早期推理偏差并显著减少蒸馏过程中的计算浪费，为训练大型语言模型，特别是在复杂推理任务中，提供了一种更有效和高效的方法。

## 5.[Keep It InMind: Benchmarking the Implicit-Association Blind Spot in Agent Memory](https://arxiv.org/pdf/2607.24368)
summary:**Core Keywords**: 代理记忆, 隐式关联盲点, InMind基准, 信息检索, 知识路由 本研究提出InMind基准测试，旨在量化并揭示现有代理长期记忆系统中因查询条件接口和缺乏知识路由而导致的“隐式关联盲点”这一结构性缺陷，指出当前检索系统无法有效利用存储的用户事实进行间接查询以提供安全、正确或恰当的响应。  该论文旨在解决代理长期记忆系统在需要检索但与查询没有直接语义关联的隐式关联事实时，无法有效应用世界知识来提供恰当响应的问题，即“隐式关联盲点”。  论文引入了InMind，一个包含125个任务的专家验证基准，覆盖十个生活领域，其中113个任务基于可引用的公共来源。通过配对控制，InMind旨在区分“事实未存储”、“模型缺乏桥接知识”或“事实已存储但未浮现”三种失败原因，并对比了将决定性记忆直接置于上下文中的骨干模型与六种主流检索系统的表现。  实验结果显示，当决定性记忆直接置于上下文中的骨干模型能回答84.0%的间接查询，而六种主流记忆系统在需要检索相同事实时，间接查询的正确率最高仅达14.4%，尽管它们在按需召回时性能高达100%。此外，即使使用维度高八倍的嵌入模型，目标召回率虽有所提升，但这种差距基本保持不变。  这项研究对AI从业者的主要启示是，目前的检索增强型代理系统在“显式召回”方面表现良好，但在“隐式关联”的“知识路由”上存在根本性缺陷，亟需开发能基于世界知识而非单纯语义相似性来判断哪些记忆应保持可见的机制。

## 6.[Mage-VL: An Efficient Codec-Native Streaming Multimodal Foundation Model](https://arxiv.org/pdf/2607.24904)
summary:**Mage-VL**, **编解码器原生**, **流式多模态基础模型**, **Mage-ViT**, **AI4AI** Mage-VL是一个高效的编解码器原生流式多模态基础模型，通过其定制的Mage-ViT分词器选择性编码动态、富含熵的区域以及采用仿生双系统架构实现主动流式感知，旨在解决标准视觉语言模型在简单流式感知任务上的计算效率低下和性能不足问题，从而实现实时多模态理解和交互。 本文旨在解决标准视觉语言模型（VLM）在简单流式感知任务中面临的计算效率低下和性能不足的Moravec悖论，并构建一个能够进行实时多模态理解和交互的高效编解码器原生流式基础模型。 核心方法是引入定制的Mage-ViT分词器，该分词器通过在稀疏锚帧（I帧）和预测帧（P帧）上利用运动向量和残差能量，选择性地编码动态、富含熵的区域，取代了统一帧采样，在16x16补丁级别将视觉Token消耗减少75%以上。此外，Mage-VL采用了AI4AI数据管道进行提示词-代码联合优化和AI驱动的性能诊断，并通过一个轻量级系统1事件门和一个因果系统2解码器的仿生双系统架构实现了主动流式感知。 Mage-ViT在约5.6亿未标记图像和1亿未标记视频帧上从头训练，其性能与在数十亿图像-文本对上训练的旗舰编码器相当或更优。Mage-VL-4B在静态任务上与Qwen3-VL-4B表现相当，但在视频理解和2D/3D空间推理方面实现了显著提升，推理速度最高可达3.5倍的实际挂钟加速，并全面超越了15B Phi-4推理-视觉基线。 此研究为AI从业者提供了一种通过编解码器原生设计和数据高效预训练策略，构建能在资源受限的流媒体环境中实现实时、高效多模态理解和交互的视觉语言模型的新范式，显著提升了处理动态视觉事件的能力，并揭示了七项关键经验发现以指导未来模型开发。

## 7.[Wonder: Video World Model Done Better](https://arxiv.org/pdf/2607.26037)
summary:**视频世界模型**, **实时生成**, **稀疏注意力**, **相机控制**, **蒸馏**  Wonder是一个通用的视频世界模型，通过对控制方法、记忆机制和训练策略的系统级协同设计，实现了实时、相机可控的世界探索，能够以16 FPS的速度合成多样化的分钟级视频，同时在长时间rollout中保持连贯的几何、外观和动态，并自然支持视频条件下的重拍。  该研究旨在解决现有交互式视频世界模型在精确控制、持久长程记忆和稳定实时推理方面面临的挑战，以构建一个能够从初始条件（如图像或视频）生成持久视觉环境，并允许用户通过控制信号进行探索的模型。  Wonder采用教师-学生蒸馏范式，首先训练一个双向视频扩散教师模型，该模型引入了基于渲染的密集坐标场的相机控制表示，提供空间对齐的运动和方向线索。接着，通过高效的稀疏注意力记忆机制支持长程生成，该机制在推理时根据查询-键相似性选择恒定数量的相关上下文token，而不是密集关注所有历史KV状态。最后，通过混合学生模型和相机感知对抗正则化等技术优化自强制蒸馏管道，以提高学生模型对控制信号的尊重能力，并保持教师模型的多样化生成模式和长程记忆。  Wonder在图像到视频（I2V）和视频到视频（V2V）两种设置下均显著提升了视觉质量和相机跟随精度。在I2V任务中，Wonder实现了0.8558的平均视觉质量评分，并将平移相对姿态误差（RPE）从0.0174降至0.0132，旋转RPE从0.1155降至0.0784。模型能够以16 FPS的稳定延迟生成分钟级视频。  Wonder通过其系统级协同设计，为AI从业者提供了一个实现高精度相机控制、长程记忆和实时生成的通用视频世界模型范例，这对于游戏创作、虚拟生产和机器人等需要交互式、持久性视觉环境的AI应用具有重要指导意义，能显著提升用户体验和生成质量。

## 8.[Visual prompt engineering for video models](https://arxiv.org/pdf/2607.25537)
summary:**视觉提示工程**, **视频模型**, **视觉推理**, **图像编辑模型**, **基础模型**  该论文研究了视频模型作为视觉推理任务的基础模型是否能从视觉提示工程 (VIPE) 中受益，这是一种自动修改任务图像以提升模型性能的方法，结果表明 VIPE 能够有效提高视频模型在多项任务上的视觉推理表现，并且可能比传统的文本提示工程或测试时缩放更有效。  该研究的主要问题是：自动修改任务图像的视觉提示工程是否能像文本提示工程提升语言模型性能一样，改善视频模型在视觉任务上的表现？  关键方法论是引入视觉提示工程 (VIPE) 框架，包括一个“想法生成器”（可以是人类或语言模型）以自然语言描述视觉编辑，一个“编辑器”（例如 Nano Banana Pro 图像编辑模型）根据指令生成图像变体，以及一个可选的“筛选器”（例如 VLM）进行质量控制。这些经过转换的图像随后被输入到视频模型（例如 Veo 3.1）进行推理，并对生成的视频进行通过/失败评分。  主要结果显示，VIPE 持续提高了视频模型的视觉推理性能。例如，在 VPCT 数据集上，Veo 3.1 模型的准确率从基线的 41.3% 提高到 59.3%。此外，研究发现视觉提示工程比单纯生成更多视频更具成本效益，通过 VIPE 变体结合 20 次测试时采样，可将准确率提升至 68.0%，而原始提示下仅为 50.0%。视频模型普遍偏好逼真的视觉上下文而非抽象输入，存在“真实感偏差”。  对 AI 从业者的主要启示是，AI/ML 工程师和数据科学家应将视觉提示工程作为一种简单、计算高效且有效的测试时扩展策略，以提升视频模型的视觉推理能力。通过将抽象或合成的任务图像转换为逼真的表示，可以更好地匹配模型的内部表示和训练分布，从而显著改善模型表现，尤其是在处理此类任务时。

summary:**潜在推理策略, 语言模型, 潜在变量分解, 变分目标, 后验崩溃**  本研究旨在将预训练语言模型p_θ(y|x)的响应分布分解为结构化的策略条件表示，通过学习潜在变量分解(r_ϕ(z|x), g_ϕ(y|x,z))并提出衡量相对于基础模型响应损失的分数信息增益的变分目标来解决标准变分推断中的后验崩溃问题，从而恢复与不同参考策略对齐的潜在编码并保留基础模型的响应分布。  该研究旨在解决如何将预训练语言模型的响应分布分解为结构化的策略条件表示，以揭示语言模型中隐含的潜在推理策略的问题。核心方法是学习一个潜在变量分解 p_θ(y|x) → (r_ϕ(z|x), g_ϕ(y|x,z))，其中路由器r将输入x映射到潜在策略z的分布，生成器g基于x和z生成响应y。为解决因生成器已能独立表示p_θ(y|x)而导致的后验崩溃问题，研究提出了一个变分目标，该目标衡量相对于基础模型响应损失的分数信息增益，并将重建压力集中在高基础模型惊奇度的token上，以促使z编码策略相关的响应变异。研究引入了一个多策略算法任务基准，并在此基准上证明所提出的变分目标能够恢复与不同参考策略对齐的潜在编码，同时保留基础模型的响应分布。该研究为AI从业者提供了分解语言模型内部复杂推理策略的方法，通过显式化这些策略，有望提升模型的透明度、可控性，并可能支持未来的策略级别干预和更有效的探索。
