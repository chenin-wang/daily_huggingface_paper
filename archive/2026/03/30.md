## 0.[PixelSmile: Toward Fine-Grained Facial Expression Editing](https://arxiv.org/pdf/2603.25728)
summary:**核心关键词**: 细粒度面部表情编辑, 扩散框架, 语义重叠, FFE数据集, 全对称联合训练 PixelSmile提出了一种基于扩散的框架，通过构建带有连续情感标注的FFE数据集并采用全对称联合训练方法，解决了细粒度面部表情编辑中存在的语义重叠问题，实现了表情语义的解耦、精确稳定的线性控制及鲁棒的身份保持。该研究旨在解决细粒度面部表情编辑中固有的语义重叠限制，实现连续、可控且精细的表情编辑，同时保持身份一致性并支持表情融合。该方法提出了PixelSmile扩散框架，利用Flex Facial Expression (FFE) 数据集的连续情感标注来解决语义重叠。核心技术包括：通过全对称联合训练（结合强度监督和对比学习）来解耦表情语义并生成更强、更易区分的表情；通过文本潜在插值实现精确稳定的线性表情控制；以及引入身份保持损失以确保身份一致性。实验结果表明，PixelSmile在细粒度表情编辑方面表现优越，在六种基本表情上的编辑准确率达到0.8627，结构混淆率最低为0.0550，并在控制线性度（CLS-6为0.8078）和身份保持方面均取得了最佳表现。该研究为AI从业者提供了一个用于细粒度面部表情编辑的标准化框架，并推动了连续及组合式面部情感操纵的AI技术发展，对于开发更精确、可控的人脸生成与编辑应用具有重要意义。

## 1.[Intern-S1-Pro: Scientific Multimodal Foundation Model at Trillion Scale](https://arxiv.org/pdf/2603.25040)
summary:**核心关键词**: **科学多模态**, **万亿参数**, **MoE模型**, **可专业化通用模型**, **强化学习**  Intern-S1-Pro是首个万亿参数科学多模态基础模型，通过空前规模的扩展和XTuner、LMDeploy等基础设施的高效支持，实现了在通用和科学领域、推理、图文理解及智能体能力上的全面提升，并掌握了百余项专业科学任务，作为“可专业化通用模型”在通用能力上达到开源模型顶级水平，在专业科学任务深度上超越了专有模型。 该研究旨在通过构建万亿参数规模的科学多模态基础模型，解决现有模型在处理科学领域复杂、多样化且涉及长尾知识的专业任务时容量不足、泛化能力受限的问题，并探索大型通用模型在专业领域超越专用模型的潜力。 Intern-S1-Pro基于SAGE框架开发，通过引入分组路由（Grouped Routing）的专家扩展策略，结合直通估计器（STE）实现稀疏专家路由的稳定梯度更新，确保万亿MoE模型的高效负载均衡和训练稳定性，其多模态能力通过原生ViT视觉编码器、傅里叶位置编码（FoPE）以及自适应采样的时间序列编码器构建，并通过专门的科学图文生成流水线和处理科学与通用数据冲突的策略进行预训练，后训练则使用FP8混合精度强化学习以提升稀疏MoE模型的稳定性。 Intern-S1-Pro在多个科学基准测试中超越了专有模型，例如在SciReasoner上得分55.5，显著高于Gemini-3-Pro的14.7和GPT-5.2的13.6；在生物学任务的案例研究中，Intern-S1-Pro在Protein-Fluorescence任务上取得78.14分，远超专用模型Biology-Instruction的2.57分，证实了大型通用模型在专业领域通过联合训练可实现更优性能。 Intern-S1-Pro的工作表明，通过大规模参数扩展和精细化的多模态架构设计，大型通用基础模型（特别是“可专业化通用模型”）在经过与特定领域数据联合训练后，不仅能处理通用任务，还能在深度和精度上超越传统专用模型，这为AI从业者在构建未来AI系统时，提供了将通用智能与专业知识深度融合的新范式，从而加速科学发现及复杂任务自动化。

## 2.[Calibri: Enhancing Diffusion Transformers via Parameter-Efficient Calibration](https://arxiv.org/pdf/2603.24800)
summary:**扩散Transformer**, **参数高效校准**, **生成质量**, **黑盒奖励优化** 本文提出Calibri，一种参数高效的方法，通过引入单个学习到的缩放参数并利用进化算法优化约100个参数，对扩散Transformer（DiTs）的组件进行校准，以显著提升生成质量并减少推理步骤。 该论文旨在通过参数高效校准，释放扩散Transformer的隐藏潜力，从而显著提升其在生成任务中的性能。 Calibri方法将DiT校准构架为黑盒奖励优化问题，通过引入单个学习到的缩放参数来调整DiT模块的贡献，并利用无梯度进化策略CMA-ES高效求解，仅修改大约100个参数。该方法支持块缩放、层缩放和门控缩放等不同粒度级别的校准。 实验结果显示，Calibri在多种文本到图像模型上持续提升性能，并减少了图像生成所需的推理步数。例如，在FLUX模型上，Calibri将HPSv3分数从11.41提高到13.48，并将所需推理步数从30减少到15。 对于AI从业者而言，Calibri提供了一种轻量级且参数高效的方法，能显著提升扩散Transformer模型的生成质量和效率，减少计算开销，使其在实际应用中更具可行性。

## 3.[RealRestorer: Towards Generalizable Real-World Image Restoration with Large-Scale Image Editing Models](https://arxiv.org/pdf/2603.25502)
summary:**图像修复**, **真实世界退化**, **大规模图像编辑模型**, **泛化能力**, **RealIR-Bench**  RealRestorer通过构建一个包含九种常见真实世界退化类型的大规模数据集，并训练一个先进的开源图像编辑模型，旨在缩小与闭源替代方案的性能差距，从而实现通用真实世界图像修复。  该研究旨在解决现有图像修复模型受限于训练数据规模和分布，导致在真实世界场景中泛化能力差的问题，同时应对大型通用模型实现高性能所需的高昂数据和计算成本。  核心方法包括构建一个覆盖九种常见真实世界退化类型的大规模合成与真实混合数据集，并基于Step1X-Edit预训练骨干模型对一个先进的开源图像编辑模型进行两阶段训练（迁移训练和监督微调）。此外，研究引入了RealIR-Bench基准测试，该基准包含464张真实世界退化图像以及专注于退化去除和一致性保持的定制评估指标。  实验结果表明，RealRestorer在开源方法中排名第一，并在所有九项任务中实现了最先进的性能，例如，在平均总分上将与Nano Banana Pro（第一名闭源模型）的差距缩小至0.007分。  对于AI从业者而言，RealRestorer提供了一个高性能的开源真实世界图像修复模型，其性能可与领先的闭源系统相媲美，显著降低了开发和应用成本，并通过新数据集和基准促进了更鲁棒、更具泛化性的AI图像处理技术发展。

## 4.[Voxtral TTS](https://arxiv.org/pdf/2603.25551)
summary:**Voxtral TTS**, **多语言语音合成**, **混合架构**, **零样本语音克隆**, **Voxtral Codec** Voxtral TTS是一个表现力强的多语言文本到语音模型，它采用语义语音token的自回归生成与声学token的流匹配相结合的混合架构，能够从最短3秒的参考音频生成自然语音，并在多语言语音克隆中表现优于ElevenLabs Flash v2.5。 该研究旨在开发一种能够从少量参考音频（最短3秒）生成自然且富有表现力的多语言语音的文本到语音（TTS）模型。 Voxtral TTS的核心方法是采用混合架构，通过自回归方式生成语义语音token，并使用流匹配模型生成声学token；这些token由从头训练的Voxtral Codec（一种采用VQ-FSQ混合量化方案的语音分词器）进行编码和解码。 在母语为英语的听众进行的人类评估中，Voxtral TTS在多语言语音克隆任务中因其自然度和表现力而受到青睐，相对于ElevenLabs Flash v2.5实现了68.4%的胜率。 该研究提供了一个高性能的多语言零样本语音克隆TTS模型，其模型权重在CC BY-NC许可下发布，为AI/ML工程师和数据科学家开发更自然、更具表现力的语音应用提供了先进的工具和开放资源。

## 5.[MSA: Memory Sparse Attention for Efficient End-to-End Memory Model Scaling to 100M Tokens](https://arxiv.org/pdf/2603.23516)
summary:**Memory Sparse Attention (MSA), 长期记忆, 大语言模型, 稀疏注意力, 线性复杂度** 本文提出Memory Sparse Attention (MSA)，这是一个端到端可训练、高效且大规模可扩展的记忆模型框架，通过可扩展的稀疏注意力、文档级RoPE等核心创新，旨在使AI模型能够处理终生级信息，克服现有大语言模型长上下文限制，并实现线性复杂度下的卓越性能。该研究旨在解决当前大语言模型（LLMs）因全注意力架构限制，有效上下文长度通常仅限于1M令牌的问题，并克服现有方法在精度、延迟、记忆动态修改和端到端优化方面的不足，最终使AI模型能处理终生级信息。论文提出了Memory Sparse Attention (MSA) 记忆模型框架，其核心技术方法包括：可扩展的稀疏注意力架构、文档级旋转位置编码（RoPE），以及结合KV缓存压缩与Memory Parallel实现100M令牌推理，并通过Memory Interleaving机制促进跨分散记忆段的复杂多跳推理。实验结果表明，MSA在训练和推理上均实现线性复杂度，并在从16K扩展到100M令牌时，性能下降不到9%，同时保持了卓越的精度稳定性。该模型在长上下文基准测试中显著超越了前沿LLMs、最先进的RAG系统和领先的记忆代理。对于AI从业者而言，MSA通过将记忆容量与推理能力解耦，为通用模型赋予内在的、终生级记忆提供了一个可扩展的基础，有望推动AI在处理大规模、长期信息场景下的应用发展。

## 6.[MACRO: Advancing Multi-Reference Image Generation with Structured Long-Context Data](https://arxiv.org/pdf/2603.25319)
summary:**多参考图像生成**, **长上下文数据**, **MacroData**, **MacroBench**, **结构化数据** 本文通过引入大规模结构化数据集MacroData和综合基准MacroBench，解决了当前多参考图像生成模型因数据瓶颈和缺乏标准化评估协议而导致的性能下降问题，并通过在MacroData上进行微调展示了多参考图像生成的显著改进。  本文旨在解决现有模型在多参考图像生成任务中，随着输入参考图像数量增加而出现的严重性能下降问题，该问题主要源于数据瓶颈以及缺乏结构化长上下文监督和标准化评估协议。  核心方法包括：1) 构建MacroData，一个包含40万样本的大规模数据集，每个样本包含最多10张参考图像，并系统地组织在定制、插图、空间推理和时间动态四个互补维度上，以全面覆盖多参考生成空间。2) 提出MacroBench，一个包含4,000样本的基准测试，用于评估生成模型在分级任务维度和输入规模上的生成一致性。  实验结果表明，在MacroData上对模型进行微调可使多参考图像生成能力获得显著提升，并且消融研究揭示了跨任务协同训练和处理长上下文复杂性的有效策略带来的协同效益。所提供的摘要中未包含具体的定量实验结果。  对于AI从业者而言，MacroData和MacroBench提供了开发和评估高级多参考图像生成模型的关键资源。该数据集的结构化长上下文特性有助于模型学习复杂的参考图像间依赖关系，而基准测试则提供了一个标准化协议来评估模型在多样化任务和不同输入规模下的性能，从而指导长上下文图像生成领域的未来研究。

## 7.[SlopCodeBench: Benchmarking How Coding Agents Degrade Over Long-Horizon Iterative Tasks](https://arxiv.org/pdf/2603.24755)
summary:**编码代理**, **迭代任务**, **代码质量**, **基准测试**, **结构侵蚀** 本文介绍了SlopCodeBench，一个语言无关的基准测试，用于评估编码代理在长期迭代任务中代码质量的退化情况，揭示了现有基准测试低估了代码扩展鲁棒性以及当前代理缺乏迭代软件开发所需的架构设计能力。 该研究旨在解决现有编码基准测试主要评估单次解决方案且严格限制代理设计决策的问题，从而无法真实衡量代码质量如何影响未来的可扩展性，目标是量化编码代理在长期迭代软件开发任务中代码质量的退化程度。 研究团队引入了SlopCodeBench，一个包含20个问题和93个检查点的语言无关基准测试，代理在此基准下重复扩展其自身先前的解决方案，面对不断演进的规范，同时被要求在不预设内部结构的情况下做出架构决策，并通过追踪冗余或重复代码的比例（冗余度）和复杂度质量集中在高复杂度函数中的比例（结构侵蚀）这两种轨迹级代码质量信号来衡量退化。 实验结果表明，在11个模型中，没有任何代理能端到端解决任何问题，最高检查点解决率仅为17.2%。代码质量稳定下降：80%的轨迹中结构侵蚀上升，89.8%的轨迹中冗余度上升。与48个开源Python仓库相比，代理生成的代码冗余度高出2.2倍，并且侵蚀程度显著更高。 对于AI从业者而言，这些结果表明，目前以通过率为主的基准测试系统性地低估了代码的可扩展性鲁棒性，并且当前的编码代理缺乏迭代软件开发所必需的设计纪律，提示AI工程师和研究人员在开发和评估编码代理时，需关注其在长期迭代任务中维护代码质量和架构健全性的能力。

## 8.[AVControl: Efficient Framework for Training Audio-Visual Controls](https://arxiv.org/pdf/2603.24793)
summary:**核心关键词**: **音视频控制, LoRA, LTX-2, 并行画布, 视频生成** AVControl是一个基于LTX-2联合音视频基础模型的轻量级可扩展框架，通过将每个控制模态训练为独立的LoRA，并利用并行画布在注意力层提供参考信号作为额外token，无需进行架构更改，解决了现有方法在视频和音频生成控制中的架构复杂性与数据效率低下的问题。 该研究旨在解决现有音视频生成控制方法在处理多样模态时训练单一整体模型或引入昂贵架构更改的局限性，旨在提供一个高效、可扩展且模块化的音视频控制框架。 其核心方法是建立在冻结的LTX-2联合音视频基础模型之上，每个控制模态（如深度、姿态、相机轨迹、音频转换）作为一个独立的LoRA适配器进行训练。该框架采用“并行画布”机制，将参考信号编码为附加token并与生成目标共同通过Transformer的自注意力层处理，同时利用LTX-2的token时间步长区分参考和生成token，避免了对位置编码的修改。 实验结果显示，在VACE基准测试中，AVControl在深度和姿态引导生成、图像修复和图像外绘制方面均优于所有评估的基线，例如在深度引导生成方面比VACE高出2.9分。该框架具有计算和数据效率，每种模态仅需少量数据集和数百到数千个训练步骤即可收敛，所有13种模态的总训练预算不到整体替代方案的三分之一。 对于AI从业者而言，AVControl提供了一个灵活且可扩展的解决方案，允许以低成本和高效率将新的控制模态集成到音视频生成模型中，显著加速了功能开发，并通过精细的推理时强度调节能力提升了生成内容的精确度和创造性。

## 9.[VFIG: Vectorizing Complex Figures in SVG with Vision-Language Models](https://arxiv.org/pdf/2603.24575)

summary:**多模态大语言模型, 手写数学, 错误诊断, 基准测试**  本文通过引入SCRATCHMATH基准，旨在解决现有MLLM在手写数学学生草稿中错误诊断而非仅生成正确答案的局限性，并通过支持错误原因解释和分类，为个性化教育反馈奠定基础。  该研究旨在弥补现有教育NLP专注于文本响应并忽视手写草稿复杂多模态信息的不足，同时解决当前MLLM侧重于生成正确答案而非诊断学生错误的问题，从而为学生手写数学草稿提供自动化的错误分析。  研究团队开发了SCRATCHMATH基准，包含1,720份中国中小学生手写数学样本，支持“错误原因解释”（ECE）和“错误原因分类”（ECC）两项任务，并定义了七种错误类型。数据集采用人机协作的严谨标注方法，涉及多阶段专家标注、审核与验证。评估了16个主流MLLM，其中ECE任务使用LLM-as-a-Judge框架，ECC任务使用准确率进行评估。  评估结果显示，与人类专家相比，MLLM在SCRATCHMATH基准上的性能存在显著差距，尤其是在视觉识别和逻辑推理方面。专有模型普遍优于开源模型，其中大型推理模型在错误解释任务中展现出潜力。例如，在o4-mini模型失败案例中，最常见的错误类型是视觉识别失败，占比36%。  该研究暴露了当前MLLM在手写数学错误诊断方面的局限性，尤其是在视觉识别和逻辑推理方面的挑战，为AI从业者指明了未来在提升模型视觉处理精度、理解复杂数学逻辑以及开发更符合教育分析流程的模型方面的研究方向，且所有评估数据和框架均已公开。
