

# Papers for 2026-03-17

## 0.[HybridStitch: Pixel and Timestep Level Model Stitching for Diffusion Acceleration](https://arxiv.org/pdf/2603.07815)
summary:**扩散模型**, **模型拼接**, **图像生成加速**, **Text-to-Image**, **混合模型**  本文提出HybridStitch，一种像素级和时间步级模型拼接的Text-to-Image生成范式，通过引入混合阶段联合使用大型和小型模型，显著加速了扩散模型的推理过程并保持生成质量。该研究旨在解决大型Text-to-Image扩散模型面临的巨大计算开销问题，以及现有模型拼接方法未能充分利用同一时间步内像素计算需求差异的局限性。HybridStitch将图像生成过程视为编辑，通过一个混合阶段将图像分解为易渲染区域和复杂区域。它首先使用小型模型构建粗略草图，然后利用大型模型对复杂区域进行精修，并基于去噪步骤间的L1距离差异动态更新掩码，实现像素级和时间步级的模型切换，同时使用KV缓存保持上下文连贯性。实验结果表明，HybridStitch在Stable Diffusion 3上实现了1.83倍的加速，其速度优于所有现有混合模型方法，同时在所有质量指标上均表现出色。这项工作为AI/ML/软件工程师提供了一种有效减少Text-to-Image生成延迟的策略，特别适用于对延迟敏感的场景，并通过精细的区域感知和多模型协同提高了计算效率。

## 1.[VQQA: An Agentic Approach for Video Evaluation and Quality Improvement](https://arxiv.org/pdf/2603.12310)
summary:**VQQA**, **视频生成**, **多智能体框架**, **VLM**, **提示优化** VQQA提出了一个统一的多智能体框架，通过动态生成视觉问题并利用视觉语言模型（VLM）的评论作为语义梯度，解决了视频生成模型输出与复杂用户意图对齐的挑战，实现了一个高效、闭环的黑盒自然语言提示优化过程。 当前视频生成模型难以使其输出与复杂用户意图对齐，且现有测试时优化方法通常计算成本高昂或需要白盒访问模型内部。 VQQA（视频质量问答）是一个统一的多智能体框架，通过动态生成视觉问题，并利用视觉语言模型（VLM）的评论作为语义梯度，取代了传统的被动评估指标，提供人类可解释、可操作的反馈，实现高效的闭环提示优化。 VQQA在T2V-CompBench上相较于原始生成模型实现了+11.57%的绝对改进，在VBench2上实现了+8.43%的绝对改进，并且显著优于现有最先进的随机搜索和提示优化技术。 对于AI从业者而言，VQQA提供了一个无需访问模型内部的黑盒自然语言接口，通过提供人类可解释的、可操作的反馈，极大地提高了视频生成模型的对齐效率和质量，特别适用于文本到视频（T2V）和图像到视频（I2V）任务的优化。

## 2.[Think While Watching: Online Streaming Segment-Level Memory for Multi-Turn Video Reasoning in Multimodal Large Language Models](https://arxiv.org/pdf/2603.11896)
summary:**多模态大语言模型 (MLLMs)，流式视频推理，分段级记忆，多轮交互，因果掩码**  “Think While Watching”框架通过维护连续的分段级记忆、采用三阶段多轮思维链数据集及训练策略、强制流式因果掩码与位置编码以及设计重叠感知与生成的推理管道，解决了多模态大语言模型在在线流媒体视频多轮推理中长程依赖建模和实时性差的问题，并在Qwen3-VL基础上显著提升了单轮准确率并减少了多轮输出tokens。  该研究旨在解决多模态大语言模型在处理连续到达的视频流时，进行在线多轮交互推理能力薄弱、现有交错式感知-生成范式导致记忆衰退和序列化瓶颈的问题。  核心技术方法是提出“Think While Watching”框架，该框架维护分段级记忆库以存储可复用证据，并通过注意力机制隐式检索相关记忆进行问答；训练方面，构建了三阶段、多轮思维链数据集，并采用匹配阶段的训练策略，同时强制执行分段级流式因果掩码和流式位置编码以确保推理的严格因果性；推理阶段则设计了高效的管道，使视频观看（感知）与思考（生成）并行重叠，并自适应选择最佳注意力后端（Flash Attention或记忆高效注意力）以减少延迟。  实验结果表明，在Qwen3-VL基础上，“Think While Watching”在StreamingBench上将单轮准确率提高了2.6%，在OVO-Bench上提高了3.79%；在多轮流式协议下，该方法在保持性能的同时，将输出token数量减少了56%。  对于AI从业者而言，该研究提供了一个实用的框架，使多模态大语言模型能够进行实时、长程和多轮的视频理解，其解耦感知-生成和显式记忆管理机制有效提升了系统响应速度并缓解了记忆衰退，显著降低了流媒体应用（如直播、机器人助手）的部署计算成本并加速了响应，对AI系统设计和部署具有重要意义。

## 3.[Spend Less, Reason Better: Budget-Aware Value Tree Search for LLM Agents](https://arxiv.org/pdf/2603.12634)
summary:**LLM Agents, Budget-Aware, Value Tree Search, Step-Level Value Estimation, Resource Allocation**  BAVT是一个无需训练的推理时框架，通过将多跳推理建模为动态搜索树，并结合步级价值估计和预算感知节点选择机制，旨在提高LLM代理在资源受限环境下的可靠性和效率。该论文旨在解决现有LLM代理在推理时计算资源消耗高效率低下的问题，具体是使代理能够在严格的计算预算限制下，避免在冗余或死胡同的路径上耗尽令牌和工具预算，从而实现更好的任务性能。BAVT通过动态搜索树模拟多跳推理过程，并引入步级价值估计器（一个残差价值预测器）来评估相对进展而非绝对状态质量，以减轻LLM自我评估的过度自信。其核心创新是一个预算感知的节点选择机制，该机制使用剩余资源比率作为节点价值的自然缩放指数，实现从广泛探索到贪婪利用的无参数、有原则的过渡，同时提供理论收敛保证。在四个多跳问答基准和两个模型家族上的评估表明，BAVT持续优于并行采样基线，尤其是在严格的低预算约束下，其性能超越了基线在4倍资源分配下的表现。BAVT证明了智能预算管理在LLM代理的部署中根本上优于蛮力计算扩展，为AI/ML工程师在资源受限的真实世界环境中部署可靠、高效的自主代理提供了一个无需训练的、适应性强的范例。

## 4.[LookaheadKV: Fast and Accurate KV Cache Eviction by Glimpsing into the Future without Generation](https://arxiv.org/pdf/2603.10899)
summary:**KV缓存驱逐, 长文本大模型, 注意力重要性分数, 预知令牌, 参数高效模块** 本文提出了LookaheadKV，一个用于Transformer大语言模型的轻量级KV缓存驱逐框架，其通过参数高效模块和可学习的预知令牌准确预测重要性分数，无需计算昂贵的草稿生成，从而实现长文本任务的快速精确驱逐。  该研究旨在解决现有“预知未来”KV缓存驱逐方法中计算昂贵的草稿生成问题，此问题导致显著的预填充开销并限制了长文本大模型在实际部署中的可行性。  LookaheadKV通过参数高效模块增强Transformer层，这些模块经过训练能以高精度预测真实的注意力重要性分数。该框架利用可学习的特殊预知令牌和预知LoRA模块生成查询，可靠地估计令牌重要性分数，从而实现在不显式生成的情况下预知未来响应。  广泛的实验证明，LookaheadKV在各种长文本理解任务中不仅优于近期有竞争力的基线方法，还将驱逐成本降低了高达14.5倍，显著加快了首令牌生成时间。  对于AI从业者，LookaheadKV为大语言模型中的KV缓存瓶颈提供了一个实用且高效的解决方案，能够以显著降低的推理延迟和更高的准确性部署长文本应用，特别适用于资源受限或对延迟敏感的环境，例如移动设备。

## 5.[Taking Shortcuts for Categorical VQA Using Super Neurons](https://arxiv.org/pdf/2603.10781)
summary:**Core Keywords**: **超神经元 (SNs)**, **视觉语言模型 (VLMs)**, **标量激活**, **分类型VQA**, **早期退出** 本研究发现，直接探查视觉语言模型（VLM）的原始标量激活（即超神经元，SNs）足以作为各种视觉接地任务的精确分类器，从而在提高分类性能的同时，实现模型推理的极早期退出并显著加速。  本文旨在解决视觉语言模型（VLM）在分类型视觉问答（Categorical VQA）任务中提升分类性能和推理效率的问题。  该研究提出一种无训练方法，通过直接探查视觉语言模型（VLM）的原始标量激活，将其作为分类预测。这种方法将关注点从注意力向量转移到微观层面的标量激活，显著增加了可发现判别性神经元的搜索空间，从而能够从第一个生成标记立即发现准确的神经元。  实验结果表明，与原始网络相比，超神经元（SNs）能稳定提升分类性能，并实现高达5.10倍的推理速度提升，同时在大型语言模型的浅层中能支持极早期退出。  这项研究为AI从业者提供了一种无训练、高效提升视觉语言模型在分类型VQA任务性能的方法，通过识别和利用模型中的关键微观激活，不仅能优化模型表现，还能显著加速推理过程，尤其适用于对实时性有高要求的应用场景。
