## 0.[Harder Is Better: Boosting Mathematical Reasoning via Difficulty-Aware GRPO and Multi-Aspect Question Reformulation](https://arxiv.org/pdf/2601.20614)
summary:**数学推理**, **难度感知**, **强化学习**, **GRPO**, **问题重构**  本文提出MathForge框架，通过难度感知群组策略优化（DGPO）算法和多维度问题重构（MQR）策略，从算法和数据两方面解决现有强化学习可验证奖励（RLVR）方法对挑战性问题重视不足的问题，从而显著提升大模型的数学推理能力。  论文旨在解决现有可验证奖励强化学习（RLVR）方法在提升大模型数学推理能力时，对更具挑战性问题缺乏重视的系统性问题，该问题源于算法层面GRPO的隐式不平衡和数据层面数据增强未系统性增加内在难度。  MathForge框架包含难度感知群组策略优化（DGPO）算法和多维度问题重构（MQR）策略。DGPO首先通过难度平衡群组优势估计纠正GRPO中策略更新幅度的隐式不平衡，并通过难度感知问题级加权优先处理难题。MQR则从添加故事背景、引入抽象术语和嵌套子问题等多维度重构问题以增加难度和多样性，同时保持原始正确答案。  广泛实验表明，MathForge在各种数学推理任务上显著优于现有方法，验证了其有效性和通用性。  MathForge的框架通过系统性地关注和解决更具挑战性的问题，为AI从业者提供了提升大型模型数学推理能力和解决复杂问题的新范式，有助于开发更强大、更鲁棒的AI推理系统。

## 1.[Advancing Open-source World Models](https://arxiv.org/pdf/2601.20540)

## 3.[DeepSeek-OCR 2: Visual Causal Flow](https://arxiv.org/pdf/2601.20552)
summary:**DeepSeek-OCR 2, DeepEncoder V2, 视觉因果流, 动态重排序, 2D推理**  本文提出了DeepSeek-OCR 2，包含新型编码器DeepEncoder V2，旨在通过赋予编码器因果推理能力，在LLM内容解释前智能地重排视觉tokens，以解决传统VLM在处理视觉tokens时采用刚性光栅扫描顺序与人类视觉感知不符的问题，从而探索2D图像理解能否通过两级级联的1D因果推理结构有效实现，为实现真正的2D推理提供新的架构方法。  该研究旨在解决传统视觉语言模型（VLM）在处理图像时，采用固定自上而下、从左到右的刚性光栅扫描顺序与人类灵活且语义连贯的视觉感知模式相矛盾的问题，并探索2D图像理解是否能通过两级级联的1D因果推理结构有效实现，以期达成真正的2D推理。  核心方法是引入DeepEncoder V2编码器，其用紧凑的LLM风格架构替代了DeepEncoder中的CLIP组件。DeepEncoder V2采用双流注意力机制，其中视觉tokens使用双向注意力以保持全局建模能力，而新引入的因果流查询（即learnable queries）则采用因果注意力。这些查询附加在视觉tokens之后，每个查询可关注所有视觉tokens及其前面的查询。通过定制的注意力掩码（视觉tokens区域双向，因果流tokens区域因果），仅将因果查询的输出馈送给LLM解码器。该架构实例化为Qwen2-0.5B，并沿用DeepSeek-OCR的3B参数MoE解码器。  DeepSeek-OCR 2在OmniDocBench v1.5上实现了91.09%的先进性能，相比DeepSeek-OCR基线，整体性能提升了3.73%。阅读顺序（R-order）的编辑距离从0.085显著降低到0.057，表明DeepEncoder V2能够根据图像信息有效选择和排列初始视觉tokens。在实际生产环境中，DeepSeek-OCR 2将在线用户日志图像的重复率从6.25%降低到4.17%，将PDF数据生产的重复率从3.69%降低到2.88%。  DeepSeek-OCR 2通过引入具有视觉因果流的LLM风格编码器，为AI从业者提供了一种实现更类人视觉理解的新范式，尤其是在处理复杂布局文档时。其提出的两级级联1D因果推理结构，为实现真正的2D推理和统一多模态编码提供了有潜力的架构方向，未来可应用于图像、音频、文本等多种模态的特征提取和token压缩，并能自然地继承LLM社区的先进基础设施优化（如MoE和高效注意力机制）。

## 4.[Reinforcement Learning via Self-Distillation](https://arxiv.org/pdf/2601.20802)
summary:**强化学习**, **自蒸馏策略优化**, **大型语言模型**, **丰富反馈**, **信用分配** 本研究引入自蒸馏策略优化（SDPO），通过将大型语言模型（LLMs）自身条件化于丰富反馈作为自教师，并将反馈指导的下一 token 预测蒸馏回策略，以解决可验证奖励强化学习（RLVR）中稀疏标量奖励导致的信用分配瓶颈问题。  该研究旨在解决大型语言模型（LLMs）在可验证奖励强化学习（RLVR）任务中面临的稀疏标量奖励导致的严重信用分配瓶颈问题，并通过引入丰富反馈强化学习（RLRF）范式，利用令牌化反馈生成稠密学习信号。  SDPO是一种在线强化学习算法，其核心思想是利用LLM自身处理丰富文本反馈的能力进行自我教学。具体而言，SDPO将当前策略在接收到环境提供的丰富令牌化反馈后，作为“自教师”，重新评估其原始尝试的 log-probabilities，并将其反馈指导的下一 token 预测蒸馏回策略，从而提供密集的 logit 级别信用分配，无需外部教师或显式奖励模型。  在科学推理、工具使用和 LiveCodeBench v6 上的竞技编程任务中，SDPO 在样本效率和最终准确率上均优于强 RLVR 基线。具体而言，在困难的二元奖励任务上，测试时应用 SDPO 可将解决方案发现速度提升至最佳-k 采样或多轮对话的 3 倍，即以少 3 倍的尝试次数达到相同的发现概率。  SDPO为AI从业者提供了一种有效利用大型语言模型训练中丰富的文本反馈（如运行时错误、评判者评估）的方法，将其转化为稠密的、 token 级别的学习信号，显著提升了模型在代码生成和复杂推理等任务上的样本效率和最终准确性。这使得在缺乏强外部教师或复杂奖励模型的情况下，LLM 也能通过自我反思机制实现性能的自我提升和对困难任务的快速发现，从而加速AI模型在实际应用中的迭代和优化。

## 5.[Spark: Strategic Policy-Aware Exploration via Dynamic Branching for Long-Horizon Agentic Learning](https://arxiv.org/pdf/2601.20209)
summary:**强化学习**, **大语言模型**, **长周期任务**, **动态分支**, **策略性探索** 为解决强化学习训练大语言模型在长周期Agent任务中面临的高质量轨迹稀缺和资源浪费问题，本文提出了SPARK框架，通过在关键决策状态动态分支实现资源高效的策略性探索，从而提升Agent的泛化能力和成功率。本文旨在解决大语言模型作为智能Agent在长周期任务训练中，因高质量轨迹稀缺和计算资源分配不均导致的探索效率低下和样本质量不足的问题。SPARK框架通过动态分支探索，在Agent的内在决策信号指导下，于关键决策点（SPARK点）选择性地扩展探索路径，构建分层树状探索结构。该方法首先利用监督微调（SFT）使模型具备生成内在探索信号的能力，随后通过强化学习优化，实现计算资源对高不确定性状态的精准分配。实验结果表明，SPARK在多个Agent任务中实现了更高的成功率和更强的泛化能力；例如，在ALFWorld任务中，SPARK仅使用20%的训练数据就达到了84.4%的成功率，超过了GRPO使用全部数据（100%）时的76.6%。这项研究为AI从业者提供了一种高效训练长周期Agent的方法，通过Agent自身的决策信号进行策略性探索，减少了对人工先验知识的依赖，有望在资源受限场景下开发出更具泛化能力和鲁棒性的Agent系统。

## 6.[Linear representations in language models can change dramatically over a conversation](https://arxiv.org/pdf/2601.20834)
summary:**语言模型表示**, **线性表示**, **上下文适应**, **事实性**, **可解释性** 本研究通过在（模拟）对话环境中分析语言模型线性表示的动态演变，发现这些表示会随着对话进程发生显著变化，从而对模型的可解释性和干预构成挑战。 本文旨在研究大型语言模型中对应于高层概念的线性表示，在对话上下文中如何动态演变。 研究人员在（模拟）对话情境中，观察语言模型中线性表示的演变，并探讨了沿表示方向进行干预在对话不同点上产生不同效果的情况，包括对模型对“事实性”和对话相关信息的表示进行分析。 线性表示在对话中会发生显著变化，例如，对话初期被表示为事实的信息在后期可能变为非事实，反之亦然。这些变化是内容依赖的，对话相关信息表示会变化，而通用信息通常得以保留。这些变化在不同模型家族和层中均稳健，且在重放对话脚本时也能观察到类似变化，但在科幻故事等明确虚构的上下文中适应性明显较弱。 这些发现挑战了现有模型可解释性和干预方法的有效性，表明静态解释或假定特征一致性可能具有误导性，AI工程师和研究人员在构建和评估可解释AI系统时，必须考虑表示的动态上下文适应性。

## 7.[AACR-Bench: Evaluating Automatic Code Review with Holistic Repository-Level Context](https://arxiv.org/pdf/2601.19494)
summary:**大语言模型**, **自动化代码审查**, **评估基准**, **仓库级上下文**, **多语言支持**  该论文引入AACR-Bench这一全面多语言、仓库级上下文自动化代码审查评估基准，旨在通过AI辅助和专家验证的标注流程克服现有基准的局限性，并为LLM驱动的ACR提供更严谨的评估标准和新的性能洞察。  该论文旨在解决现有自动化代码审查（ACR）评估基准存在的两大局限：一是依赖嘈杂不完整的原始Pull Request（PR）评论作为真值，限制了问题检测范围；二是缺乏多语言及仓库级上下文支持，影响了评估结果的泛化性。  为解决上述挑战，研究者引入了AACR-Bench基准，该基准提供跨文件和多编程语言的完整上下文。其核心方法是采用“AI辅助、人类专家验证”的标注流程，通过结合模型生成与人工验证来发现原始PR中常被忽视的潜在缺陷。  AACR-Bench的标注流程使缺陷覆盖率提高了285%。对主流LLM在该基准上的广泛评估表明，以往的评估可能因数据限制而低估或误判了模型的实际能力。研究发现，上下文的粒度/级别和检索方法的选择显著影响ACR性能。  对于AI从业者而言，该研究揭示了开发LLM驱动的ACR系统时，必须考虑上下文的粒度、检索方法，并认识到这些因素对ACR性能的影响会因LLM模型、编程语言和使用范式（如Agent架构）而异，从而指导其设计更高效、更具泛化性的ACR解决方案。

## 8.[SERA: Soft-Verified Efficient Repository Agents](https://arxiv.org/pdf/2601.20789)
summary:**SERA, SVG, 编码智能体, 监督微调, 私有代码库定制** SERA是一种高效的编码智能体训练方法，通过监督微调和软验证生成技术，实现了针对私有代码库的快速、廉价定制，并在完全开源模型中达到最先进性能，同时显著降低了成本。 本文旨在使开源编码智能体能够经济高效地针对私有代码库进行专业化，从而克服现有训练成本高昂和复杂性高的理论障碍。 SERA采用监督微调（SFT）训练，其核心是软验证生成（SVG）方法，该方法通过比较两次模型生成补丁的行级重叠进行“软验证”，替代传统的单元测试，从而无需测试基础设施并能从任意代码库生成数千条合成轨迹。 SERA模型在完全开源编码智能体中实现了最先进的性能，并可与Devstral-Small-2等前沿开源模型性能相媲美；同时，创建SERA模型的成本比强化学习方法便宜26倍，比以前的合成数据方法便宜57倍，即可达到同等性能。 这项工作为AI开发者和软件工程师提供了以极低成本对开源模型进行私有代码库定制的实用方法，极大地加速了开放编码智能体的研究和应用，解决了闭源系统在隐私和知识产权方面的局限。

## 9.[OmegaUse: Building a General-Purpose GUI Agent for Autonomous Task Execution](https://arxiv.org/pdf/2601.20380)

summary:**Core Keywords**: 自由手绘草图, 动态意图, 动画生成, 视觉-语言模型, 运动图形 本文介绍了一种交互范式，用户通过自由手绘草图向视觉-语言模型（VLM）传达动态意图，并将其应用于运动图形工作流，通过三阶段研究验证了草图与AI交互在弥合动画创作意图与结果之间鸿沟、以及在3D动画和视频生成中的潜力。 该研究旨在解决现有AI内容生成方法中，自由手绘草图的开放性和人类塑造意图的核心作用被忽视的问题，通过探索自由手绘草图在动画创作中表达动态意图的方式，实现动态内容的自动生成。 核心方法是构建一个基于视觉-语言模型（VLM）的系统，该系统通过三阶段迭代设计：首先，用户绘制自由手绘草图故事板，VLM将其解释并生成Manim Python动画代码。其次，系统引入自适应澄清提示（如快速确认、多项选择、填写数值、文本/上传），以解决草图的固有歧义。最后，用户可以直接在生成的视频帧上通过视觉编辑或文本提示进行迭代细化，以调整动画细节。 研究发现，自由手绘草图能以最少输入传达动画意图，其固有歧义需用户参与澄清，且草图能视觉引导视频细化。具体地，三阶段用户研究（共24名参与者）表明，通过澄清机制，24次尝试中的19次产出动画结果更接近用户预期；同时，与仅使用草图输入相比，澄清和细化阶段显著提升了用户对动画结果的“对齐度”和“控制感”。 对于AI从业者，这项研究揭示了草图与AI交互在弥合动画创作中意图与结果之间鸿沟的巨大潜力。它强调了在AI辅助内容生成中，通过结合VLM的语义理解能力和用户主动参与的澄清与迭代细化机制，能够实现从模糊意图到精确动画的渐进式创作流程，并支持更自由、协作式的动态内容生成。
