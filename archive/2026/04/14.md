## 0.[FORGE:Fine-grained Multimodal Evaluation for Manufacturing Scenarios](https://arxiv.org/pdf/2604.07413)
summary:**多模态大语言模型 (MLLMs)**, **制造场景**, **细粒度评估**, **多模态数据集**, **领域特定知识** 本文引入了FORGE基准，通过构建包含细粒度领域语义的真实世界2D图像和3D点云高质量多模态数据集，评估了18个最先进的MLLMs在工件验证、结构表面检测和装配验证三项制造任务上的性能，揭示了显著的性能差距，并发现领域特定知识不足而非视觉基础是主要瓶颈，为域适应制造MLLMs提供了实际途径。  该研究旨在通过提供一个严格的基准和可操作的训练资源，解决当前MLLMs在制造场景中因数据稀缺和缺乏细粒度领域语义而无法满足现实世界需求的评估困境。  FORGE构建了一个大规模多模态数据集，包含真实世界的2D图像和3D点云，并标注了模型编号等细粒度领域语义。研究设计了工件验证、结构表面检测和装配验证三项核心制造任务，并以多项选择题形式评估了18个主流MLLMs在零样本、参考条件和上下文演示设置下的表现。  评估结果显示，当前MLLMs在细粒度推理和微观表面分析方面存在显著性能差距，且瓶颈分析指出，领域特定知识不足是主要限制因素。通过对FORGE数据进行监督微调，一个紧凑的3B参数模型在未见过的制造场景中准确率相对提升高达90.8%。  这些发现对AI从业者有重要意义，表明未来制造MLLM的开发应侧重于获取和整合细粒度领域特定知识，而非仅仅提升通用视觉感知能力。FORGE数据集为训练紧凑型、域适应MLLMs以实现工业应用中的显著性能提升提供了实际资源。

## 1.[EXAONE 4.5 Technical Report](https://arxiv.org/pdf/2604.08644)
summary:**视觉语言模型, 多模态预训练, 文档理解, 长文本推理, 工业智能** EXAONE 4.5是LG AI Research发布的第一个开源视觉语言模型，通过将专用视觉编码器整合到现有EXAONE 4.0框架中，并利用大规模文档中心数据进行原生多模态预训练，旨在显著提升文档理解和韩语上下文推理能力，并广泛改进通用语言能力，支持长上下文推理和企业级应用。 本研究旨在开发一个开源的视觉语言模型，以解决现实世界工业环境中复杂的多模态挑战，特别是提升模型在文档理解、长上下文推理以及韩国语境推理方面的性能，并支持广泛的工业应用场景。 EXAONE 4.5通过将一个1.2B参数的视觉编码器与EXAONE 4.0 32B语言模型集成，实现原生多模态预训练；模型采用混合注意力机制、GQA和MTP模块，视觉编码器使用2D ROPE，语言模型使用1D ROPE；模型通过两阶段预训练策略在精心策划的大规模文档中心数据上进行训练；并通过SFT直接集成上下文扩展至256K tokens，并结合LDPO/LGROUPER和GRPO进行后训练。 比较评估显示，EXAONE 4.5在通用基准测试中表现出竞争力，并在文档理解任务中超越了同等规模的现有先进模型，例如在OMNIDOCBENCH V1.5上取得81.2分，优于GPT-5 mini的77.0分；在LIVECODEBENCH V6语言基准测试中得分81.4，优于所有比较模型。 对于AI从业者，EXAONE 4.5的开源以及其在文档理解和长上下文推理等工业智能领域表现出的卓越性能，为开发和部署针对特定行业应用（如制造质量控制、企业工程和维护）的多模态AI系统提供了强大的基础模型和技术路线。

## 2.[Matrix-Game 3.0: Real-Time and Streaming Interactive World Model with Long-Horizon Memory](https://arxiv.org/pdf/2604.08995)
summary:**核心关键词**: **实时交互世界模型**, **长时记忆**, **扩散模型**, **视频生成**, **矩阵游戏** Matrix-Game 3.0 是一个记忆增强的实时交互世界模型，旨在通过数据、模型和推理的系统性改进，实现720p分辨率下长视频的实时生成，同时保持长时空一致性。  该研究旨在解决现有交互式视频生成方法在同时实现长时记忆、长期时间一致性、高分辨率实时生成方面的挑战，这些限制了其在现实世界场景中的应用。  Matrix-Game 3.0 的核心方法包括：首先，开发了升级版工业级无限数据引擎，集成了虚幻引擎合成数据、AAA游戏数据和真实世界视频增强数据，以大规模生产高质量Video-Pose-Action-Prompt四元组数据；其次，提出了长时一致性训练框架，通过建模预测残差并重新注入不完美生成帧实现自校正，同时通过相机感知记忆检索和注入确保长时空一致性；最后，设计了基于DMD的多段自回归蒸馏策略，并结合模型量化和VAE解码器剪枝实现高效实时推理。  实验结果显示，Matrix-Game 3.0 使用5B模型在720p分辨率下可实现高达40 FPS的实时生成，并能在一分钟长的序列中保持稳定的记忆一致性。将模型扩展到28B参数后，进一步提升了生成质量、动态性和泛化能力。  这项工作为AI从业者提供了一条工业级可部署世界模型的实用途径，通过其在实时高分辨率长视频生成和长时记忆一致性方面的突破，为构建更复杂、更具交互性的AI系统奠定了基础。

## 3.[RefineAnything: Multimodal Region-Specific Refinement for Perfect Local Details](https://arxiv.org/pdf/2604.06870)
summary:**Core Keywords**: **区域特定图像细化**, **多模态扩散**, **Focus-and-Refine**, **边界一致性损失**, **RefineEval**  该论文提出了RefineAnything，一个多模态扩散模型，它利用Focus-and-Refine策略和边界一致性损失，实现了高精度、区域特定的图像细化，同时严格保留了未编辑的背景区域。当前图像生成模型普遍存在局部细节崩溃问题，如文本、标志和细微结构的扭曲，且现有指令驱动编辑模型常忽略这些缺陷或无意中改变背景。本文旨在解决这一问题，通过在用户指定区域恢复精细细节，并确保图像非编辑区域保持严格不变。核心方法包括：1) Focus-and-Refine策略，该策略基于裁剪-缩放可显著提升局部重建的观察，通过重新分配分辨率预算至目标区域以提高细化效率和效果，并结合混合掩码回填以严格保留背景；2) 引入边界一致性损失，以减少接缝伪影并改善回填的自然性。在RefineEval基准测试中，RefineAnything相比现有基线实现了显著改进，并在背景保留方面达到了近乎完美的性能，例如MSEbg和LPIPSbg误差均为0.000，SSIMbg达到0.9997，同时区域保真度也显著提升（MSE/LPIPS重建误差为0.020/0.155）。RefineAnything为AI从业者提供了一个实用的解决方案，可用于高精度局部图像精修，例如在不改变背景的情况下修复产品图像中的扭曲文本或标志，显著提升了生成式AI工具在实际工作流中的可用性和可靠性。

## 4.[Multi-User Large Language Model Agents](https://arxiv.org/pdf/2604.08567)
summary:**多用户LLM代理, 多主体决策, 指令遵循, 隐私保护, 协作协调** 本文系统性研究了多用户大型语言模型（LLM）代理，通过形式化多主体交互并设计压力测试场景，评估了当前LLM在指令遵循、隐私保护和协作协调方面的能力，并揭示了其系统性缺陷。  本研究旨在解决现有LLM系统主要为单主体交互优化，难以同时服务具有冲突利益、信息不对称和隐私限制的多个用户的问题。  核心方法是首先将多用户交互形式化为多主体决策问题，然后引入统一的多用户交互协议，并设计了三个有针对性的压力测试场景，即指令遵循、隐私保护和协作协调，以评估LLM的能力。  研究结果显示，前沿LLM在处理冲突用户目标时难以保持稳定的优先级，在多轮交互中隐私泄露日益增多，并且在需要迭代信息收集的协作协调中存在效率瓶颈。  这些发现对AI从业者来说意味着，需要开发具有原生多用户接口、遵循原则的冲突解决机制和强大的长期隐私保护能力的LLM代理，从而超越单一主体优化范式。

## 5.[ECHO: Efficient Chest X-ray Report Generation with One-step Block Diffusion](https://arxiv.org/pdf/2604.09450)
summary:**胸部X射线报告生成, 扩散模型, 一步推理, 直接条件蒸馏, 响应非对称扩散** ECHO是一种高效的扩散式视觉语言模型（dVLM），通过新颖的直接条件蒸馏（DCD）框架实现稳定的单步逐块推理，并结合响应非对称扩散（RAD）训练策略，旨在解决胸部X射线报告生成中现有模型推理延迟高和文本连贯性差的问题。该研究旨在解决胸部X射线报告生成中，传统自回归视觉语言模型推理延迟高以及多步去噪扩散模型仍需多次迭代，且单步去噪易因均值场偏差导致文本连贯性下降的问题。核心方法是ECHO模型，它采用直接条件蒸馏（DCD）框架，通过从策略性扩散轨迹构建非因子化监督来编码联合token依赖性，减轻均值场限制并实现稳定的单步逐块推理；同时引入响应非对称扩散（RAD）训练策略以提高训练效率并保持模型有效性。实验结果表明，ECHO超越了现有最先进的自回归方法，将RaTE提高了64.33%，SemScore提高了60.58%，同时实现了8倍的推理速度提升，且未损害临床准确性。对于AI从业者而言，ECHO通过其单步逐块扩散和高效蒸馏方法，为开发高吞吐量、高准确性的医疗影像报告生成系统提供了新的范例，显著降低了推理延迟，提升了系统在实际医疗场景中的应用效率。

## 6.[ELT: Elastic Looped Transformers for Visual Generation](https://arxiv.org/pdf/2604.09168)
summary:**Elastic Looped Transformers**, **参数效率**, **循环Transformer**, **视觉生成**, **循环内自蒸馏 (ILSD)**  ELT引入了一种基于循环Transformer架构的、高度参数高效的视觉生成模型，通过迭代的权重共享Transformer块和循环内自蒸馏（ILSD）实现参数量大幅减少并支持任意时间推理，显著提升了视觉合成的效率边界。  该研究旨在解决传统生成模型依赖深层、独特Transformer层导致参数量过大的问题，目标是开发一种参数高效、能保持高质量合成，并支持推理时计算成本与生成质量之间动态权衡的视觉生成模型。  ELT采用循环Transformer架构，利用迭代的权重共享Transformer块而非堆叠独特的层来减少参数。为有效训练，提出了循环内自蒸馏（ILSD）方法，该方法将学生配置（中间循环）从教师配置（最大训练循环）中蒸馏出来，确保模型在不同深度上保持一致性。  ELT在等推理计算设置下，将参数量减少了4倍，在ImageNet 256x256图像生成任务上实现了2.0的竞争性FID，并在UCF-101视频生成任务上实现了72.8的FVD。  ELT为AI从业者提供了一种在资源受限环境下部署高性能视觉生成模型的新范式，通过 Any-Time inference 能力，可以在不重新训练模型的情况下，根据实际的计算预算和对生成质量的要求，动态调整循环次数，从而灵活地平衡计算成本与性能。

## 7.[AgentSwing: Adaptive Parallel Context Management Routing for Long-Horizon Web Agents](https://arxiv.org/pdf/2603.27490)
summary:**长程Web智能体**, **LLM上下文管理**, **AgentSwing**, **自适应并行路由**, **前瞻性决策** 本文针对长程信息检索中大型语言模型智能体有限上下文容量管理这一关键瓶颈，提出了AgentSwing自适应并行上下文管理路由框架，通过并行扩展多个上下文管理分支并采用前瞻性路由选择最有前景的延续，显著提升了长程Web智能体的搜索效率与终端精度。该研究旨在解决长程信息检索任务中大型语言模型智能体上下文容量有限且现有静态管理策略无法适应动态演变上下文的挑战。研究方法首先引入一个概率框架，通过搜索效率和终端精度两个互补维度量化长程成功；在此基础上，AgentSwing在每个触发点并行扩展多个上下文管理分支，并利用前瞻性路由机制选择最有前景的延续路径。实验结果表明，AgentSwing持续优于强静态上下文管理方法，常以高达3倍更少的交互轮次达到或超越其性能，并提高了长程Web智能体的最终性能上限。对于AI从业者而言，所提出的概率框架提供了一个有原则的视角来分析和设计长程智能体的未来上下文管理策略，并通过自适应路由展示了提升智能体性能的有效路径。
