## 0.[ClawGUI: A Unified Framework for Training, Evaluating, and Deploying GUI Agents](https://arxiv.org/pdf/2604.11784)
summary:**GUI智能体, 强化学习, 评估, 部署, 开源框架**  ClawGUI是一个统一的开源框架，通过提供统一的强化学习训练、标准化评估和真实设备部署基础设施，解决了当前GUI智能体开发面临的环境不稳定、评估协议不一致和实际部署困难的瓶颈。该研究旨在解决GUI智能体开发中缺乏连贯全栈基础设施，导致在线RL训练、评估和实际部署受限的问题。ClawGUI核心方法由三部分组成：ClawGUI-RL提供可扩展的在线RL训练（整合GiGPO与Process Reward Model实现密集步长监督），ClawGUI-Eval确保标准化评估（覆盖6个基准和11+模型），ClawGUI-Agent则将智能体部署到Android、HarmonyOS和iOS设备，采用混合CLI-GUI控制和持久化个性化记忆。实验结果显示，通过此框架训练的ClawGUI-2B在MobileWorld GUI-Only上实现了17.1%的成功率，相对同规模MAI-UI-2B基线提高了6.0%；同时，ClawGUI-Eval在6个基准和11+模型上达到了95.8%的官方结果复现率。这为AI从业者提供了一个开放、标准化的GUI智能体开发平台，极大地提升了训练效率、评估可靠性和实际部署能力，从而加速GUI智能体在真实场景的应用与技术迭代。

## 1.[KnowRL: Boosting LLM Reasoning via Reinforcement Learning with Minimal-Sufficient Knowledge Guidance](https://arxiv.org/pdf/2604.12627)
summary:**KnowRL, 大语言模型推理, 强化学习, 知识点指导, 最小充分指导** KnowRL是旨在通过强化学习提升大语言模型推理能力的训练框架，它将提示设计视为最小充分指导问题，并通过构建紧凑、交互感知的知识点子集来解决奖励稀疏性问题。该研究旨在解决强化学习在提高大语言模型推理能力时面临的严重奖励稀疏性以及现有提示方法冗余、不一致和训练开销大的问题。KnowRL将指导分解为原子知识点（KPs），并采用受限子集搜索（CSS）策略来构建紧凑、交互感知的知识点子集，同时明确优化了“剪枝交互悖论”以实现鲁棒的子集选择。在强化学习训练过程中，KnowRL通过对单个知识点可能有效但多个知识点联合移除反而有害的悖论进行优化，从而实现鲁棒的子集选择。实验结果表明，KnowRL-Nemotron-1.5B在八个推理基准测试中始终优于强RL和提示基线。在没有KP提示的情况下，其平均准确率达到70.08%，已超过Nemotron-1.5B 9.63个百分点；而在选定KP的辅助下，性能进一步提升至74.16%，在该规模上建立了新的最先进水平。对于AI从业者而言，KnowRL提供了一种可扩展且高效的LLM推理指导范式，通过最小化冗余信息和专注于关键知识结构，降低了计算开销并显著提高了学习效率。

## 2.[Toward Autonomous Long-Horizon Engineering for ML Research](https://arxiv.org/pdf/2604.13018)
summary:**自主AI研究**, **长周期ML研究工程**, **AiScientist**, **分层编排**, **File-as-Bus** AiScientist 是一个为实现自主长周期ML研究工程而设计的系统，其核心原则是通过结构化编排和持久状态连续性来获得强大的长周期性能。 本研究旨在解决自主AI研究中长周期ML研究工程的固有困难，即代理需在任务理解、环境设置、实现、实验和调试等环节持续保持连贯进展。 其核心方法是结合分层编排和权限范围的File-as-Bus工作空间，顶层协调器通过简洁摘要和工作空间地图进行阶段级控制，而专业代理则通过持久化分析、计划、代码和实验证据等工件反复重新定位。 实验结果显示，AiScientist在PaperBench上平均得分提升10.54点，在MLE-Bench Lite上达到81.82%的Any Medal。消融研究进一步证实，移除File-as-Bus协议会使PaperBench得分降低6.41点，MLE-Bench Lite降低31.82点。 这些发现对AI从业者的主要启示是，长周期ML研究工程本质上是一个通过持久项目状态协调专业工作的系统问题，而非纯粹的局部推理问题，强调了系统级设计在提升AI工程性能中的关键作用。

## 3.[SPPO: Sequence-Level PPO for Long-Horizon Reasoning Tasks](https://arxiv.org/pdf/2604.08865)
summary:**序列级PPO (SPPO)**, **大语言模型 (LLMs)**, **推理任务**, **上下文赌博机**, **解耦标量值函数**  SPPO是一种可扩展算法，通过将LLMs推理过程重构为序列级上下文赌博机问题并采用解耦标量值函数，实现了PPO的样本效率与结果驱动更新的稳定性结合，为对齐推理LLMs提供了资源高效的框架。该研究旨在解决标准PPO在长链式思维（CoT）推理任务中存在的时序信用分配不稳定性和价值模型内存成本过高问题，同时避免GRPO等无Critic方法所需的多样本计算开销。SPPO将推理过程重新定义为序列级上下文赌博机问题，将整个响应视为原子动作，并通过一个解耦的标量值函数来估计成功概率，从而在不进行多样本采样的情况下获得低方差的优势信号。在数学基准测试中，SPPO显著超越了标准PPO，并媲美了计算密集型组基方法的性能。SPPO为AI从业者提供了一个高效且稳定的框架，用于在资源有限的条件下对LLMs进行推理任务对齐，尤其是在稀疏奖励的长时序场景中，提升了训练吞吐量和稳定性。

## 4.[Turing Test on Screen: A Benchmark for Mobile GUI Agent Humanization](https://arxiv.org/pdf/2604.09574)

## 5.[Nemotron 3 Super: Open, Efficient Mixture-of-Experts Hybrid Mamba-Transformer Model for Agentic Reasoning](https://arxiv.org/pdf/2604.12374)

## 8.[The Blind Spot of Agent Safety: How Benign User Instructions Expose Critical Vulnerabilities in Computer-Use Agents](https://arxiv.org/pdf/2604.10577)
summary:**计算机使用代理, 代理安全, OS-BLIND基准, 意外攻击, 攻击成功率** 该论文引入了OS-BLIND基准，旨在评估计算机使用代理在用户指令看似良性但危害在任务上下文或执行结果中出现的意外攻击条件下的安全性，发现现有代理普遍存在严重漏洞，尤其是在多代理系统中，并强调了现有防御措施的局限性，为解决代理安全盲点提供了具体基础。 该研究旨在解决现有计算机使用代理（CUA）安全评估的盲点，即忽视了用户指令完全良性但危害在任务上下文或执行结果中出现的“意外攻击”场景，并通过引入新基准OS-BLIND系统评估和揭示CUA在此类条件下的关键漏洞。 研究者构建了OS-BLIND基准，该基准包含300个人工制作的任务，涵盖12个类别、8个应用程序和2个威胁集群（环境嵌入式威胁和代理主动引发的危害），并以此评估了前沿模型和代理框架的安全性。 评估发现，大多数CUA的攻击成功率（ASR）超过90%，即使安全对齐的Claude 4.5 Sonnet也达到了73.0%的ASR。当Claude 4.5 Sonnet部署在多代理系统中时，ASR甚至从73.0%上升到92.7%。分析表明，现有安全防御措施在用户指令良性时保护有限，安全对齐主要在前几步激活，并且多代理系统中的任务分解会掩盖有害意图，导致模型失效。 OS-BLIND基准的发布以及其揭示的CUA在良性指令下的严重安全漏洞，为AI从业者提供了开发更鲁棒代理安全机制的明确方向，尤其是在防御多代理系统中的任务分解导致的漏洞和加强代理持续安全对齐方面具有重要指导价值。

## 9.[Many-Tier Instruction Hierarchy in LLM Agents](https://arxiv.org/pdf/2604.09443)
summary:**大型语言模型代理, 指令层级, 多层指令层级, 指令冲突, ManyIH-Bench**  本文针对大型语言模型代理在真实世界中处理多源指令冲突时，现有固定层级指令层级（IH）范式不足的问题，提出了多层指令层级（ManyIH）范式，允许任意数量的指令特权级别，并发布了首个ManyIH基准测试ManyIH-Bench，旨在评估模型在细粒度、可扩展指令冲突解决中的能力。  **Main Research Question or Objective**: 该研究旨在解决大型语言模型代理在处理来自系统消息、用户提示和工具输出等多种来源、具有不同信任和权威级别的指令冲突时，如何可靠地遵循最高特权指令以确保安全性和有效性。  **Key Methodology**: 作者提出了多层指令层级（ManyIH）范式，通过专用特权提示接口（PPI）将特权值动态分配给每条指令，并使用序数或标量值在提示中编码特权信息，以解决任意多层特权指令冲突。为评估此能力，研究构建了首个ManyIH基准测试ManyIH-Bench，包含853个代理任务（427个编码任务和426个指令遵循任务），每个任务涉及多达12个不同特权级别的冲突指令。  **Primary Results**: 实验结果表明，即使是当前最先进的模型在ManyIH-Bench上的表现也较差，最佳模型（Gemini 3.1 Pro）的准确率仅为42.7%。随着指令层级数量的增加，模型性能持续下降，准确率降幅在6.8%至24.1%之间。此外，模型对特权信息的表示形式高度敏感，例如GPT 5.4和Opus 4.6仅因提示格式变化就导致了超过8%的准确率下降。  **Principal Implication for AI Practitioners**: 这些发现揭示了当前模型在细粒度指令冲突解决方面的脆弱性，凸显了在代理设置中，迫切需要开发明确针对可扩展、表示鲁棒的特权推理的方法和架构。

## 10.[VideoFlexTok: Flexible-Length Coarse-to-Fine Video Tokenization](https://arxiv.org/pdf/2604.12887)
summary:**视频分词**, **粗粒度到细粒度**, **变长序列**, **生成流解码器** VideoFlexTok提出了一种视频分词器，通过变长、粗粒度到细粒度的令牌序列表示视频，使下游模型能根据需求自适应地调整令牌数量并实现高效训练，同时能以更少令牌生成长视频。 该研究旨在解决现有视频分词器采用固定大小三维网格令牌，导致下游模型需学习预测所有像素级细节，从而带来高学习复杂性的问题。 VideoFlexTok将视频表示为变长、粗粒度到细粒度的令牌序列，其中首批令牌捕获语义和运动等抽象信息，后续令牌则添加细粒度细节；其生成流解码器能从任意数量的令牌重建逼真视频。 VideoFlexTok在类别到视频和文本到视频生成任务上实现了与三维网格令牌相当的生成质量（gFVD和ViCLIP分数），但模型尺寸小5倍（1.1B vs 5.2B）；它还能够使用仅672个令牌（比传统三维网格分词器少8倍）生成10秒81帧视频，大幅降低了计算成本。 对于AI从业者而言，VideoFlexTok提供了一种更高效、灵活的视频表示方法，允许根据特定任务需求调整视频细节级别和令牌数量，从而显著降低训练成本和计算资源消耗，尤其利于长视频生成和更小模型的开发。
