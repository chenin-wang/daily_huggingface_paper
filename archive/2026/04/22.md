

# Papers for 2026-04-22

## 0.[Extending One-Step Image Generation from Class Labels to Text via Discriminative Text Representation](https://arxiv.org/pdf/2604.18168)
summary:**MeanFlow**, **文本条件图像生成**, **判别性文本表示**, **少步生成**, **LLM文本编码器** 该研究通过引入具有高判别性的LLM文本编码器并调整MeanFlow生成流程，首次实现了高效的文本条件少步图像合成，显著提升了生成性能，并为该领域提供了实用参考。 该论文旨在解决MeanFlow少步图像生成从固定类别标签条件扩展到灵活文本条件时，现有LLM-based文本编码器集成效果不佳的问题，目标是实现高效且高质量的文本条件图像合成。 研究发现，由于MeanFlow生成步骤极少（如一步），文本特征表示需具备高判别性。基于此洞察，论文利用一个经过验证具备所需语义属性的强大LLM-based文本编码器，并将其适配到MeanFlow框架中，以实现文本条件生成。 研究成功实现了首次高效的文本条件少步图像合成，并在广泛使用的扩散模型BLIP30-NEXT上进行了验证，结果显示，该模型在4步推理时GenEval分数达到约0.90，展示了显著的生成性能提升。 这项工作为AI从业者提供了在少步文本条件图像生成中有效集成强大文本编码器的实用指导，强调了文本特征判别性在极少生成步骤下的关键作用，有助于推动高效T2I模型的开发。

## 1.[WebCompass: Towards Multimodal Web Coding Evaluation for Code Language Models](https://arxiv.org/pdf/2604.18224)
summary:**WebCompass**, **多模态**, **网络编码**, **评估基准**, **代码语言模型** WebCompass引入了一个全面的多模态基准，通过统一的生命周期评估来衡量网络工程能力，旨在解决现有基准在评估代码语言模型端到端网络编码能力时，未能充分衡量视觉保真度、交互质量和代码库级推理的不足。 该研究旨在解决现有代码语言模型网络编码基准的局限性，即未能有效评估模型的视觉保真度、交互质量和代码库级推理能力。 WebCompass基准涵盖文本、图像和视频三种输入模态，以及生成、编辑和修复三种任务类型，共七种任务类别；它采用多阶段、人机协作的管道策划高质量实例，并在评估端针对编辑和修复任务采用了清单引导的“LLM即法官”协议，对生成任务则提出了新颖的“Agent即法官”范式，该范式能自主在真实浏览器中执行生成的网站并合成测试用例。 实验结果表明，闭源模型总体上更强大且平衡；编辑和修复任务呈现不同的难度曲线，其中修复任务能更好地保持交互性但执行仍具挑战性；美学是模型，尤其是开源模型的持续瓶颈；框架选择显著影响结果，Vue框架始终更具挑战性，而React和Vanilla/HTML则表现更强。 WebCompass揭示了闭源模型在网络编码方面优于开源模型，并强调美学是持续的瓶颈，这为AI从业者指明了方向，即未来的代码语言模型开发应更侧重于提升视觉保真度、交互质量及在不同前端框架下的综合性能，以实现更接近人类接受测试标准的端到端网络编码能力。
