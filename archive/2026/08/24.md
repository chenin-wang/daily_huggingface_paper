## 2.[4DAnyone: Create Anyone in 4D from a Casual Monocular Video](https://arxiv.org/pdf/2608.20335)
summary:**Core Keywords**: **4DAnyone, 4D Gaussian Splatting (4DGS), Reference Context Packing (RCP), Target Context Routing (TCR), multiview video generation** **1-Sentence Core Summary**: 4DAnyone提出了一个框架，通过生成重建级的多视角一致性视频，并将其提升为4D高斯泼溅(4DGS)模型，实现了从未校准单目视频重建4D人体的目标，解决了现有视频扩散模型在扩展到大量目标视角时一致性难以维持的瓶颈问题。 **Main Research Question or Objective**: 该研究旨在解决从非校准单目视频重建4D人体的问题，具体挑战在于现有相机控制视频扩散模型在生成数十个目标视角时，由于注意力上下文限制，导致跨视角外观指导减弱和全局结构漂移，无法保持重建所需的一致性。 **Key Methodology**: 4DAnyone通过两种互补设计解决了上述瓶颈：一是**Reference Context Packing (RCP)**，它将不断增长的参考视角压缩为固定长度的混合分辨率上下文，将参考上下文复杂度从O(N)降至O(1)；二是**Target Context Routing (TCR)**，它在去噪过程中动态旋转目标视角分组，在高噪声步传播跨组上下文并在低噪声步稳定细节。此外，该框架构建了MVGameHuman数据集并结合其他光照舞台和真实视频数据集进行训练。 **Primary Results**: 实验结果表明，4DAnyone在DNA-Rendering和DyMVHumans数据集上均优于现有方法，在生成视频一致性方面，其在DNA-Rendering数据集上的PSNR（信噪比）指标达到24.33，并且在下游4DGS重建和泛化能力方面表现出色。 **Principal Implication for AI Practitioners**: 这项研究为AI/ML工程师提供了一个在从随意捕获的单目视频生成高质量、多视角一致的4D人体模型方面的新范式，通过解决视频扩散模型在大规模多视角生成中的一致性挑战，为具身AI、沉浸式内容创作和虚拟现实等应用场景提供了更稳健的4D重建解决方案。

## 3.[SWE-bench Science: Can Coding Agents Resolve Engineering Tasks in Science?](https://arxiv.org/pdf/2608.19799)
summary:**SWE-bench Science, 科学软件工程, 编码智能体, 基准测试, 故障分析** 本文介绍了SWE-bench Science，一个针对科学软件工程的仓库级基准测试，用于评估编码智能体解决科学工程任务的能力及识别其故障机制，并揭示了科学知识对修复性能的复杂影响。  该研究旨在评估编码智能体在科学软件工程任务中的表现及其失败原因，特别是它们在修复科学软件时是否能保持科学结论的有效性。  核心方法是构建SWE-bench Science基准测试，包含来自98个GitHub仓库的119个任务，涵盖20个科学领域，并将其分为问题驱动、专家探索和工程集成三种范式。研究通过手动分析智能体的失败尝试来识别四种重复性科学故障机制，并进行了配对消融实验以分析科学辅助信息的影响。  评估结果显示，即使是表现最佳的智能体Claude Code with Opus-5 (max)，其Pass@1评分也低于50%，凸显了科学软件工程的重大挑战。研究确定了四种主要故障机制：科学知识或抽象缺陷、错误探索或表面修复、不完全修复覆盖或系统集成、以及科学知识泛化失败。配对消融实验表明，科学知识并非总是能带来益处：基础扎实的信息可以改进平均性能和token效率，而对齐不当的指导会引发锚定效应且不一定提高精确修复成功率。  对于AI从业者而言，该研究揭示了当前编码智能体在处理科学软件工程任务时的局限性，特别是在科学抽象、系统集成和知识泛化方面的不足，为未来智能体开发提供了具体的改进方向。

## 4.[WithEveryone: Unified Planning and Identity Grounding for Group Image Generation](https://arxiv.org/pdf/2608.20336)
summary:**统一规划**, **身份接地**, **群组图像生成**, **布局引导身份损失**, **身份保持** WithEveryone 提出了一个统一的群组图像生成框架，通过将选定的身份作为寻址标记注入，预测结构化的身份-布局计划并将其渲染为视觉条件，同时利用布局引导身份损失和身份表示强制训练机制，实现了多达十个参考身份的群组图像生成，显著提高了身份保持性并避免了直接复制参考人脸。 该研究旨在解决多人物场景下身份保持图像生成模型在处理大量指定人物时可靠性下降的问题，特别是如何保持每个身份的独特性、将其绑定到特定人物和位置，并有效监督训练时预测人脸与参考身份的对应关系。 WithEveryone 采用统一框架，将每个选定的身份注入为寻址标记，预测结构化的身份-布局计划，并将其渲染为视觉条件，核心方法包括使用布局引导身份损失（Layout-Grounded ID Loss），通过标注人脸区域直接监督目标身份，避免了基于嵌入的人脸匹配的不稳定性；以及身份表示强制（ID Representation Forcing）机制，在图像合成前为每个身份训练预测。 在一个身份不重叠的基准测试中，WithEveryone 实现了最高的上下文目标身份相似度，将人脸相似度从 GPT-Image 2 的 0.462 提高到 0.499，同时将复制-粘贴伪影从 0.169 降低到 0.055，并且覆盖了 97.3% 的请求身份，重复率仅为 2.8%。 这项研究对 AI 从业者的主要启示是，通过显式的身份-布局接地，可以实现身份保持生成模型在不依赖直接复制参考人脸的情况下，有效扩展到生成更大型群组图像，显著提升了多人物图像生成的可靠性和质量。

## 5.[MemTrapBench: Benchmarking Cognitive Traps in LLM Memory Use](https://arxiv.org/pdf/2608.20202)
