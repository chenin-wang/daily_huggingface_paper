## 0.[Achieving Gold-Medal-Level Olympiad Reasoning via Simple and Unified Scaling](https://arxiv.org/pdf/2605.13301)
summary:**奥林匹克推理, 监督微调, 强化学习, 测试时扩展, 领域泛化** 本文介绍了一种简单统一的策略，将预训练推理骨干模型转化为严谨的奥林匹克级解算器，通过逆困惑度课程的监督微调、两阶段强化学习以及测试时扩展，使模型在数学和物理奥林匹克竞赛中达到金牌水平并展现出强大的科学推理泛化能力。  该研究旨在解决如何通过紧凑、领域统一的方法，将一个预训练推理骨干模型提升至奥林匹克级别的推理性能，特别是在长程数学和科学问题解决方面。  核心方法是一个多阶段策略：首先，通过逆困惑度课程的监督微调（SFT）灌输严谨的证明搜索和自检行为；其次，通过两阶段强化学习（RL）——从可验证奖励的粗粒度RL到更精细的证明级RL——扩展这些行为；最后，通过测试时扩展（TTS）提升模型解决性能。具体实施中，一个30B-A3B骨干模型在约340K条8K以下token轨迹上进行SFT，随后进行200步RL训练。  最终模型SU-01在IMO-ProofBench上通过直接生成达到57.6%，经过测试时扩展后达到70.2%。在IMO 2025和USAMO 2026比赛中，SU-01（通过TTS）均获得35分，与人类最高总分持平，并且超越了IPhO 2024/2025的金牌线。  这项研究为AI从业者提供了一个高效、统一的框架，用于开发在复杂推理任务中达到专家级性能的语言模型，证明了通过结构化微调、分阶段RL和推理时自修正，即使是紧凑型模型也能实现顶尖水平的领域泛化能力。

## 1.[Self-Distilled Agentic Reinforcement Learning](https://arxiv.org/pdf/2605.15155)
summary:**Self-Distilled Agentic Reinforcement Learning, OPSD, LLM Agents, Token-level Gating, Multi-turn Interaction**  SDAR (Self-Distilled Agentic Reinforcement Learning)将策略自蒸馏(OPSD)视为一个门控辅助目标，同时保留强化学习(RL)作为主要优化骨干，通过将分离的token级别信号映射到sigmoid门，强化教师认可的正向差距token上的蒸馏并软化负向教师拒绝，从而解决了RL在LLM智能体长程交互中监督信号粗糙以及OPSD在多轮智能体中不稳定的问题，并在多个基准测试和模型规模上取得了显著性能提升。该研究旨在解决强化学习在后训练大型语言模型(LLM)智能体中存在的轨迹级奖励信号监督粗糙问题，以及现有策略自蒸馏(OPSD)方法在多轮智能体训练中面临的不稳定性，以及对负面教师拒绝处理不当的问题。该论文引入了SDAR方法，将OPSD作为门控辅助目标，并以RL作为主要优化骨干；SDAR的核心技术是将分离的token级别信号通过一个sigmoid门进行调制，以强化教师认可的正向差距token上的蒸馏，同时软化处理负向教师拒绝。SDAR在Qwen2.5和Qwen3系列的LLM模型上进行了验证，结果显示在ALFWorld上性能比GRPO提升了+9.4%，在Search-QA上提升了+7.0%，在WebShop-Acc上提升了+10.2%，并成功避免了朴素GRPO+OPSD组合的不稳定性，同时在不同模型规模上持续优于混合RL-OPSD基线。SDAR通过引入token级别门控机制来选择性地蒸馏教师信号，为AI工程师和研究人员提供了一种更稳定、高效的LLM智能体训练范式，尤其在处理多轮长程交互任务时，能够有效整合特权知识，显著提升模型性能，并降低传统蒸馏方法带来的不稳定性。

## 2.[Causal Forcing++: Scalable Few-Step Autoregressive Diffusion Distillation for Real-Time Interactive Video Generation](https://arxiv.org/pdf/2605.15141)

## 3.[SANA-WM: Efficient Minute-Scale World Modeling with Hybrid Linear Diffusion Transformer](https://arxiv.org/pdf/2605.15178)
summary:**SANA-WM**, **世界模型**, **长视频生成**, **混合线性扩散Transformer**, **相机控制** SANA-WM是一个2.6B参数的开源世界模型，其核心目标是高效生成高保真、720p、分钟级视频，并实现精确相机控制，通过混合线性扩散Transformer架构和四项关键设计，在保持视觉质量的同时显著提升了效率。 该研究旨在解决在可接受的数据、训练计算和推理成本下，实现高保真、720p、分钟级相机控制世界模型生成的问题。 SANA-WM架构包含四项核心设计：(1) 混合线性注意力机制结合帧级Gated DeltaNet (GDN) 与 softmax 注意力实现高效长上下文建模；(2) 双分支相机控制确保精确的6-DoF轨迹依从性；(3) 两阶段生成管线通过长视频精炼器提升质量和一致性；(4) 鲁棒标注管线从公共视频中提取准确的公制尺度6-DoF相机姿态。 SANA-WM仅使用约213K公共视频片段进行度量尺度姿态监督训练，在64块H100上15天内完成训练，并能在单个GPU上生成60秒视频片段；其蒸馏变体可在单个RTX 5090上通过NVFP4量化在34秒内去噪一个60秒720p视频片段。相比现有开源基线，SANA-WM实现了36倍更高的吞吐量和更强的动作跟随精度，同时保持了可比的视觉质量。 SANA-WM通过显著降低数据、训练计算和推理硬件成本，使高保真、相机控制的世界模型生成更易于实现，为AI从业者提供了可扩展的世界建模解决方案。

## 4.[MemLens: Benchmarking Multimodal Long-Term Memory in Large Vision-Language Models](https://arxiv.org/pdf/2605.14906)
summary:**大型视觉语言模型**, **多模态长期记忆**, **基准测试**, **记忆增强智能体**, **长上下文视觉语言模型**  本研究引入了MEMLENS，一个包含789个问题、涵盖五种记忆能力和四种标准上下文长度的多模态多会话对话基准测试，旨在系统比较长上下文大型视觉语言模型和记忆增强智能体在需要多模态证据的长期记忆任务上的表现，并发现它们的互补性失败模式，从而推动混合架构的发展。  论文旨在解决现有基准测试未能系统比较长上下文大型视觉语言模型（LVLMs）和记忆增强智能体在需要真实多模态证据的长期多模态交互任务上的表现的问题。  核心方法是构建了MEMLENS基准测试，包含789个问题，涵盖信息提取、多会话推理、时间推理、知识更新和拒绝回答五种记忆能力，并在32K-256K四种标准上下文长度下，采用跨模态词元计数方案进行评估。通过图像消融研究，确认了任务解决需要视觉证据。  主要实验结果表明，解决MEMLENS需要视觉证据：移除证据图像导致两个前沿大型视觉语言模型在80.4%的包含图像证据的问题上准确率降至2%以下。长上下文LVLMs在短上下文上表现出高准确率但随对话增长而下降；记忆增强智能体则长度稳定但在存储压缩下失去视觉保真度。多会话推理能力对大多数系统而言，准确率上限低于30%，且两种方法均未能独立解决任务。  主要启示是，这些结果促使AI从业者开发结合长上下文注意力机制与结构化多模态检索的混合架构，以克服现有方法的互补性局限。

## 5.[MemEye: A Visual-Centric Evaluation Framework for Multimodal Agent Memory](https://arxiv.org/pdf/2605.15128)
summary:**长周期代理记忆, 多模态, 视觉中心评估, 评估框架, 视觉证据粒度**  本文介绍了MemEye，一个视觉中心评估框架，旨在通过测量决策性视觉证据的粒度（从场景级到像素级）和检索证据的使用方式（从单一证据到演化合成）两个维度，评估多模态代理的长期记忆能力，并揭示现有架构在保留细粒度视觉细节和推理视觉状态变化方面的不足。  主要研究问题或目标是解决现有评估未能有效测试多模态代理保留细粒度视觉证据进行后期推理，以及处理随时间变化的视觉状态的难题。  MemEye框架包含视觉证据粒度（X轴，从场景级到像素级）和记忆推理深度（Y轴，从原子检索到演化合成）两个维度。在此框架下，构建了一个涵盖8个生活场景任务、371个问题的基准，并利用消融驱动的验证门来评估可回答性、快捷方式抗性、视觉必要性和推理结构。  对13种记忆方法和4种VLM骨干模型的评估表明，现有架构在保留细粒度视觉细节和推理随时间变化的视觉状态方面仍显不足。MemEye基准测试显示出比现有基准更强的视觉证据不可替代性，其中SRAG(V)在开放式评估中LLM-as-a-Judge得分为0.4937，在多项选择题中EM得分为0.6177。  研究结果表明，未来多模态记忆系统应结合图像证据、文本或结构化状态记录，并集成证据路由、时间跟踪和细节提取机制，以有效过滤无关历史、利用时间信号并避免选择过时证据，从而构建更鲁棒的长期多模态代理。

## 8.[WildClawBench: A Benchmark for Real-World, Long-Horizon Agent Evaluation](https://arxiv.org/pdf/2605.10912)

## 9.[STALE: Can LLM Agents Know When Their Memories Are No Longer Valid?](https://arxiv.org/pdf/2605.06527)
