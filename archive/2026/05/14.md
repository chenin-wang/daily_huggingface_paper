## 1.[MemPrivacy: Privacy-Preserving Personalized Memory Management for Edge-Cloud Agents](https://arxiv.org/pdf/2605.09530)

## 2.[δ-mem: Efficient Online Memory for Large Language Models](https://arxiv.org/pdf/2605.12357)
summary:**δ-mem**, **大型语言模型**, **在线记忆**, **联想记忆**, **低秩修正** δ-mem是一种轻量级记忆机制，通过紧凑的在线联想记忆状态增强冻结的全注意力骨干网络，将历史信息压缩为固定大小的状态矩阵，并通过读出生成对骨干网络注意力计算的低秩修正，显著提高了大型语言模型在需要长期历史信息场景中的性能。 该研究旨在解决大型语言模型在长期交互和代理系统中有效积累和重用历史信息的挑战，避免了简单扩展上下文窗口带来的高成本和低效问题。 δ-mem的核心方法是通过一个紧凑的在线联想记忆状态（OSAM）增强冻结的全注意力骨干网络，该OSAM将历史信息压缩为一个固定大小的8x8状态矩阵，通过delta-rule学习动态更新，并利用其读取结果为骨干网络的注意力计算生成低秩修正。 实验结果显示，仅使用8x8的在线记忆状态，δ-mem将平均得分提高到冻结骨干网络的1.10倍，比最强的非δ-mem记忆基线高1.15倍，并在记忆密集型基准测试中表现出更大增益，例如在MemoryAgentBench上达到1.31倍，在LoCoMo上达到1.20倍。 对于AI从业者，这一发现意味着可以通过一个紧凑的在线状态直接耦合注意力计算，在无需进行全面微调、替换骨干网络或显式上下文扩展的情况下，即可为大型语言模型实现高效记忆能力。

## 8.[AlphaGRPO: Unlocking Self-Reflective Multimodal Generation in UMMs via Decompositional Verifiable Reward](https://arxiv.org/pdf/2605.12495)

## 9.[MCP-Cosmos: World Model-Augmented Agents for Complex Task Execution in MCP Environments](https://arxiv.org/pdf/2605.09131)

## 13.[Towards On-Policy Data Evolution for Visual-Native Multimodal Deep Search Agents](https://arxiv.org/pdf/2605.10832)
