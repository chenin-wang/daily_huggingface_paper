## 0.[UniVidX: A Unified Multimodal Framework for Versatile Video Generation via Diffusion Priors](https://arxiv.org/pdf/2605.00658)
summary:**视频扩散模型, 多模态视频生成, 统一框架, 条件生成, LoRA** UniVidX是一个统一的多模态框架，利用视频扩散模型（VDM）先验知识实现通用视频生成，通过将像素对齐任务表述为共享多模态空间内的条件生成问题，同时适应模态特定分布并确保跨模态一致性。 该研究旨在解决现有视频扩散模型在多模态图形任务中通常为每个特定问题设置训练单独模型，导致输入-输出映射固定并忽略模态间关联性的局限，从而实现通用视频生成。 UniVidX通过随机条件掩蔽（SCM）实现全向条件生成；通过解耦门控LoRA（DGL）使用模态特定LoRA并在模态为生成目标时激活以保留VDM先验；以及通过跨模态自注意力（CMSA）共享键值并保持模态特定查询以促进信息交换和对齐。 实验结果表明，UniVidX的两个实例化模型（UniVid-Intrinsic和UniVid-Alpha）在各自任务上均取得了与现有最佳方法相当的性能，并展现出强大的泛化能力，即使仅在少于1,000个视频的有限数据集上进行训练。 对于AI从业者而言，UniVidX提供了一个统一且数据高效的多模态视频生成范式，通过其灵活的条件生成能力和跨模态对齐机制，显著降低了为每个新任务开发独立模型的复杂性和资源需求，并提升了模型在数据受限情况下的泛化性能。

## 1.[Web2BigTable: A Bi-Level Multi-Agent LLM System for Internet-Scale Information Search and Extraction](https://arxiv.org/pdf/2604.27221)
summary:**多智能体系统, 双层架构, 网络到表格搜索, 自进化学习, 共享工作空间** Web2BigTable是一个用于互联网规模信息搜索和提取的双层多智能体LLM系统，它通过上层编排器分解任务和下层工作代理并行解决子问题，并结合闭环运行-验证-反思过程及持久化外部记忆实现自进化更新，从而支持深度推理和跨实体结构化聚合两种搜索范式。该研究旨在解决现有智能体网络搜索系统在处理单一目标深度推理和跨多实体异构源结构化聚合任务时所面临的困难。Web2BigTable采用双层多智能体框架，其中上层编排器将任务分解为子问题，而下层工作代理则并行解决这些子问题。系统通过闭环运行-验证-反思过程和持久化、人类可读的外部记忆，实现任务分解和执行的联合改进及各智能体的自进化更新。此外，工作代理通过共享工作空间协调，可视化部分发现，以减少冗余探索、协调冲突证据并适应出现的覆盖不足。Web2BigTable在WideSearch基准测试中达到了新的SOTA，Avg@4成功率为38.50（是第二名的7.5倍），行F1为63.53（比第二名高25.03），项F1为80.12（比第二名高14.42），并在XBench-DeepSearch深度搜索任务中也表现出泛化能力，准确率达到73.0。Web2BigTable提出的双层多智能体架构及其自进化和协调机制，为AI从业者提供了处理互联网规模信息搜索和提取任务的有效范式，尤其在需要兼顾深度推理和广度结构化聚合的复杂场景中，能显著提升信息抽取效率和准确性。

## 2.[Map2World: Segment Map Conditioned Text to 3D World Generation](https://arxiv.org/pdf/2605.00781)
summary:**3D世界生成, 分割图条件, 结构化潜空间, 细节增强网络, 全局一致性**  Map2World提出一种新颖的文本条件3D世界生成框架，利用用户定义的任意形状和尺度的分割图，通过结构化潜空间中的潜在融合和细节增强网络，生成具有全局尺度一致性和丰富细节的高质量3D世界。该研究旨在解决现有3D世界生成方法受限于网格布局、缺乏全局对象尺度一致性以及难以处理复杂场景的挑战。其核心方法包括在结构化潜空间中应用潜在融合策略，以实现空间扩展并支持多文本驱动的任意形状区域生成；同时引入细节增强网络来生成精细细节，同时通过全局结构信息保持整体场景连贯性。模型还利用预训练3D资产生成器TRELLIS的强大先验知识，并通过光谱域参数化优化初始潜在变量以实现尺度感知。实验结果表明，Map2World在GPTscore评估中平均达到7.93/10，优于现有方法SynCity的7.48/10，并在世界质量（WQ）指标上取得7.76分，证实了其在用户可控性、尺度一致性和内容连贯性方面的显著优势。对于AI从业者而言，Map2World提供了一个灵活且可扩展的工具，能够生成高保真、语义对齐的3D世界，这对于沉浸式内容创作、自动驾驶模拟和虚拟现实等需要复杂、逼真3D环境的应用具有重要价值。

## 3.[Let ViT Speak: Generative Language-Image Pre-training](https://arxiv.org/pdf/2605.00809)
summary:**GenLIP, Vision Transformer, 多模态大语言模型, 生成式预训练, 门控注意力**  GenLIP是一个为多模态大语言模型设计的极简Vision Transformer生成式预训练框架，它通过单个Transformer直接从视觉token预测语言token，采用标准语言建模目标，旨在更好地对齐视觉编码器与大语言模型的自回归特性，并在多模态基准测试中展现出卓越的简洁性、可扩展性和性能。  该研究旨在解决现有视觉-语言预训练方法中目标不匹配和架构复杂性问题，为多模态大语言模型提供一个更直接、高效和可扩展的视觉编码器。  GenLIP采用统一的Transformer编码器处理连接后的视觉和文本序列，通过MROPE和Prefix-LM注意力机制增强跨模态交互。为缓解注意力汇聚问题，该框架引入了门控注意力机制调节信息流，并采用两阶段预训练：先在固定低分辨率图像上进行大规模数据预训练（80亿样本），后对多分辨率、原生纵横比图像进行适应性微调。  主要结果显示，在Qwen2.5-1.5B设置下，GenLIP在L/16、So/16和g/16模型规模上的整体平均得分（ALL AVG）分别比SigLIP2高出2.5、2.0和3.7点，特别是在Doc&OCR基准上平均高出4.3、3.3和5.9点。尽管使用了显著更少的80亿预训练样本，GenLIP仍能匹配或超越现有强基线模型，并在多分辨率图像的继续预训练后，进一步提升OCR和图表理解等细节敏感任务的性能。  GenLIP的极简主义生成式预训练范式为AI工程师和研究人员提供了一个直接、高效且可扩展的MLLM视觉编码器构建基础，它通过更少的数据实现了竞争甚至卓越的性能，特别在OCR和图表理解等细节敏感任务中表现出色，这表明简化架构和目标函数能有效提升多模态模型的训练效率和可扩展性。

## 4.[From Skill Text to Skill Structure: The Scheduling-Structural-Logical Representation for Agent Skills](https://arxiv.org/pdf/2604.24026)

## 5.[Prox-E: Fine-Grained 3D Shape Editing via Primitive-Based Abstractions](https://arxiv.org/pdf/2604.23774)

## 8.[Learning while Deploying: Fleet-Scale Reinforcement Learning for Generalist Robot Policies](https://arxiv.org/pdf/2605.00416)
