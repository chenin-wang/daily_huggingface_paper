## 0.[DVAO: Dynamic Variance-adaptive Advantage Optimization for Multi-reward Reinforcement Learning](https://arxiv.org/pdf/2605.25604)
summary:**动态方差自适应优势优化, 多奖励强化学习, 大语言模型, 群相对策略优化, 优势函数** 本文提出了动态方差自适应优势优化(DVAO)方法，通过动态调整组合权重并抑制噪声，解决了多奖励强化学习中现有标量化方法导致的训练不稳定和忽略跨目标相关性的问题，从而实现了大语言模型在多目标任务中更稳定的训练和卓越的性能。该研究旨在解决大语言模型在多奖励强化学习环境下，现有奖励组合和优势组合等标量化方法导致的训练不稳定、优势函数幅度过大以及忽略跨目标相关性等挑战。DVAO通过在每次rollout中根据各目标奖励的经验方差动态调整组合权重，优先提升具有强学习信号的目标权重并抑制噪声，同时通过数学证明确保优势函数幅度有界以维持训练稳定性，并引入自适应的跨目标正则化机制。在数学推理和工具使用基准测试中，使用Qwen3和Qwen2.5模型进行的广泛实验表明，DVAO显著优于所有基线方法，例如在Qwen3-4B-Base模型上，DVAO的平均准确率达到42.19%，高于GRPO的39.91%，实现了更优的多目标帕累托前沿和鲁棒的训练稳定性。对于AI从业者而言，DVAO提供了一种无需手动调优固定超参数即可在多目标任务中实现卓越帕累托最优策略的方法，能够无缝平衡准确性与长度/格式约束，从而显著提升大语言模型在复杂实际应用中的鲁棒性、稳定性和多功能性。

## 1.[WBench: A Comprehensive Multi-turn Benchmark for Interactive Video World Model Evaluation](https://arxiv.org/pdf/2605.25874)
summary:**交互式世界模型, 多轮基准, 评估维度, 自动化度量, 性能诊断**  WBENCH是一个全面的多轮交互式世界模型评估基准，旨在通过五大维度、多样化的测试用例和22个自动化子度量，解决现有基准碎片化、缺乏统一评估标准的问题。该研究旨在解决交互式世界模型评估中现有基准碎片化、无法对模型所需的所有能力进行系统统一评估的挑战。  WBENCH构建了一个包含289个测试用例和1,058个交互轮次的多轮基准，每个用例定义了世界设置和多轮交互序列，涵盖多样化的场景、风格、主体及第一/第三人称视角，并支持导航、主体动作、事件编辑和视角切换四种交互类型；其中导航统一了文本、6-DoF姿态和离散动作控制，确保不同原生输入接口模型的公平评估；评估体系包含22个结合专业视觉模型和大型多模态模型的自动化子度量，且所有度量均经过人类判断验证。实验结果表明，在评估的20个最先进模型中，没有一个模型能在所有五个评估维度上表现出色。例如，导航性能随轮次增加下降最快，从第一轮到第四轮下降了33点。  WBENCH通过揭示现有交互式世界模型在物理、可控性和一致性方面的细粒度失败模式，为AI研究人员和工程师提供诊断性洞察，从而指导更可靠、更全面的世界模型架构和训练策略的开发。

## 2.[Macaron-A2UI: A Model for Generative UI in Personal Agents](https://arxiv.org/pdf/2605.24830)
summary:**生成式UI**, **个人智能体**, **A2UI**, **LoRA**, **强化学习** 本文提出了Macaron-A2UI模型，旨在通过构建大规模生成式UI语料库和A2UI-Bench基准，并采用参数高效的LoRA监督微调与奖励驱动强化学习两阶段训练方法，使个人智能体能够动态合成自然语言和可执行UI操作，以解决传统纯文本交互的瓶颈问题，其最佳模型在A2UI-Bench上无需显式Schema提示即可达到75.6的整体分数，超越了最强基线，从而推动了个人智能体生成式UI的发展。 本文旨在解决个人智能体在处理复杂、以用户为中心的任务时，静态纯文本聊天作为瓶颈的问题，通过使智能体能够根据交互上下文实时动态合成正确的控件、选项和状态，从而超越纯文本交互。 研究方法包括：首先，构建了一个包含14,245个智能体轮次样本（其中10,210个为UI轮次）的大规模A2UI生成式UI语料库，该语料库整合了MultiWOZ 2.2、SGD、ESConv和AnnoMI四种异构对话源，并采用规则与LLM混合管道、确定性后处理及四级验证与修复机制。其次，引入了A2UI-Bench基准，用于评估原子、深度和广度任务，并采用L1（协议正确性）、L2（任务构建质量）、L3（交互质量）语言侧指标及VLM视觉评估。最后，模型训练采用两阶段参数高效方法：先进行LoRA监督微调以学习基本响应格式和协议合规的UI动作，再通过奖励驱动的组相对策略优化（GRPO）进行微调，以提升交互质量，该奖励函数综合考量结构、任务构建和用户效用。 实验结果表明，最佳的Macaron-A2UI模型（Macaron-A2UI-Venti，基于GLM-5.1训练）在A2UI-Bench上取得了75.6的整体语言侧分数，且无需显式Schema提示。这一结果超越了提供完整Schema提示的最强基线模型（如GPT-5.4的74.1分和Gemini-3.1 Pro的71.0分），证明了生成式UI能力可以被模型内化学习，而非依赖于推理时的重度Schema提示。 这项研究为AI从业者提供了训练个人智能体生成动态、结构化UI的有效方法和基准，使其能够超越静态纯文本交互，从而无需在推理时提供复杂的Schema提示即可实现更直观、高效的用户体验。所发布的模型、基准和评估协议为生成式UI的未来研发奠定了基础。

## 4.[TriSplat: Simulation-Ready Feed-Forward 3D Scene Reconstruction](https://arxiv.org/pdf/2605.26115)
summary:**前馈3D场景重建**, **定向三角形基元**, **模拟就绪**, **稀疏视图**, **网格提取** TriSplat是一种前馈重建网络，它通过在单次前向传播中预测局部3D点图、三角形属性和相机参数，直接从稀疏、未定位的输入图像中以定向三角形基元表示场景并导出模拟就绪的网格，从而实现更忠实的几何重建和有竞争力的新视图渲染质量。  该论文旨在解决现有前馈散斑网络在3D场景重建中的局限性，即这些网络主要基于高斯基元间接表示表面，需要昂贵的后处理步骤才能提取可用网格，尤其是在无姿态、稀疏视图设置下。  TriSplat作为一个前馈网络，能从输入图像中共同预测局部3D点图、三角形属性、相机姿态和可选内参；它从预测的点图构建几何法线，通过图像条件法线头部进行精修，并将其转换为稳定的局部坐标系以参数化三角形；此外，它采用单法线引导策略稳定早期训练，并通过不透明度和模糊调度逐步锐化表面表示以实现直接网格提取。  在RealEstate10K数据集（6视图）上的实验表明，TriSplat在网格渲染下实现了0.190的Chamfer距离和0.622的F1分数，在CD和F1上分别比最强高斯基线（YoNoSplat）提高了0.077和0.179。同时，其网格渲染PSNR达到24.69 dB，比最强高斯基线高出2.75 dB，且在6视图下端到端时间比最快高斯基线快33倍（0.57秒对比18.7秒）。  对于AI从业者而言，TriSplat提供了一个实用的、模拟就绪的3D场景重建方案，它直接输出表面三角形形成的显式网格。这消除了对复杂耗时的后处理网格提取（如TSDF融合）的需求，使得输出可以直接被物理引擎、碰撞检测器和标准渲染管线使用而无需任何转换，从而显著简化了具身AI、机器人和游戏开发的工作流程。

summary:**原生多模态建模**, **融合范式**, **输入输出对偶性**, **统一Transformer** 本文针对原生多模态（NMM）架构设计空间定义不足的问题，通过形式化定义架构原生性、根据输入输出对偶性组织现有模型并提供全面的工业级调查，旨在为社区向确定性NMM框架的过渡提供路线图，以实现卓越的多模态性能。  **主要研究问题或目标**: 本文旨在解决原生多模态架构设计空间定义不充分的问题，这阻碍了社区评估新兴模型原生性程度以及为特定下游任务选择最优架构的能力。  **核心方法**: 本文通过形式化定义架构原生性来区分非原生范式中的“中融合”和“早融合”，并从输入输出对偶性角度将现有原生模型分为三类：(i) Multi-to-Text（M2T），用于跨模态理解，输出仅为文本；(ii) Multi-to-Target（M2G），用于场景导向的生成，如图像、音频和视频；以及(iii) Multi-to-Multi（M2M），用于统一的对称输入输出建模。此外，本文还从工业角度系统地剖析了从架构协调、大规模数据整理到全栈训练方案、推理部署及全面评估的NMM端到端流程。  **主要结果**: 抽象没有提供具体的量化实验结果，但明确指出原生多模态建模实现了卓越的多模态性能，并呈现了一个全面的工业级调查路线图，其中理解和生成在统一的Transformer范式中无缝共存。  **对AI实践者的主要启示**: 本文为AI研究人员和工程师提供了一个结构化路线图，通过明确定义架构原生性、分类现有模型以及系统性地分析NMM的端到端开发流程，有助于他们理解并实践原生多模态建模，从而开发出更具原则性和鲁棒性的多模态AI系统。

## 6.[Personalize-then-Store: Benchmarking and Learning Personalized Memory for Long-horizon Agents](https://arxiv.org/pdf/2605.25535)
summary:**大语言模型记忆系统**, **个性化记忆策略**, **PerMem-Bench**, **会话级存储门控** 该论文引入了PerMem-Bench，首个用于评估LLM代理个性化记忆系统的基准，并提出了会话级存储门控框架，证实个性化在理想条件下能显著提升记忆保留，但指出准确的门控仍是一个开放且关键的挑战。 该论文旨在探究LLM驱动的记忆系统能否学习个性化记忆策略，以解决现有通用静态策略无法适应用户间“值得存储”上下文差异，导致记忆预算浪费和长期任务关键上下文丢失的问题。 核心方法包括两方面：一是推出了PerMem-Bench，作为首个评估个性化记忆系统的基准，其特点是包含跨多年、多领域和多样用户角色的交互历史；二是在记忆个性化研究中提出了会话级存储门控这一轻量级框架，该框架能选择性地跳过瞬态会话的记忆操作。 研究结果证实，在完美门控条件下，个性化能带来显著的记忆保留增益。然而，研究也揭示了准确实现会话级门控仍是一个开放且关键的挑战。 对于AI从业者而言，研究结果表明个性化记忆管理对长周期LLM代理的效率至关重要，特别是在有限记忆预算下。尽管个性化在提升记忆保留方面潜力巨大，但如何开发出能够准确识别每个用户和每个会话“值得存储”上下文的门控机制，是未来AI技术发展和应用中的一个关键研究方向。

## 7.[ParaVT: Taming the Tool Prior Paradox for Parallel Tool Use in Agentic Video Reinforcement Learning](https://arxiv.org/pdf/2605.20342)
summary:**大型多模态模型 (LMMs), 强化学习 (RL), 并行视频工具调用, 工具先验悖论, PARA-GRPO**  ParaVT是首个多智能体端到端RL训练框架，通过在单轮中并行调用多个时间窗口裁剪工具解决现有顺序工具调用方法中的错误传播、上下文污染和推理成本线性扩展问题，并提出PARA-GRPO机制解决强化学习中出现的工具先验悖论，从而显著提升了长视频理解性能和训练时格式符合度。  该论文旨在解决现有长视频理解LMMs中顺序视频处理工具调用效率低、错误传播和推理成本高的问题，并克服在RL训练中因预训练工具先验导致的格式不稳定性及跳过工具的奖励捷径问题。  论文引入ParaVT框架，这是一个首个多智能体端到端强化学习训练的并行视频工具调用框架，允许LMMs在单轮中并行调度多个时间窗口裁剪工具。为解决在RL训练中发现的“工具先验悖论”，提出PARA-GRPO机制，该机制通过两种互补机制增强标准RL：一是针对最易崩溃的结构化令牌位置应用有针对性的格式奖励；二是进行每提示帧预算随机化，以创建调用工具而非跳过工具能产生可衡量奖励信号的训练提示。  在六个长视频理解基准测试中，ParaVT相较于Qwen3-VL基线平均提升了+7.9%。PARA-GRPO将训练时格式符合度从0.13提高到0.64。  该研究揭示，随着工具能力在现代LMMs中日益内部化，强化学习必须与现有先验知识协同作用。ParaVT为智能体强化学习提供了一个通用范式，对于开发更健壮、高效且能够有效利用外部工具的大型多模态模型具有指导意义，尤其在长视频理解等复杂任务中。

summary:**Core Keywords**: **递归流匹配**, **生成模型**, **时空动力学**, **自洽性**, **科学仿真** 本文提出递归流匹配（RecFM），一个通过在离散化尺度上强制自洽来预测复杂时空动力学的生成框架，显著提升了科学系统的速度和准确性。 现有物理系统生成模型在实现高物理精度同时避免高计算成本时面临速度与保真度的关键权衡，本文旨在解决这一问题。 RecFM的核心方法是递归建模一系列轨迹，通过在不同离散化尺度上强制轨迹自洽来对齐共享空间状态，从而减少离散化误差并提高性能。 在具有挑战性的科学基准测试中，RecFM相对于主流扩散模型模拟器实现了高达20倍的速度提升，并提高了预测准确性；同时，与传统流匹配相比，均方误差降低超过15%。 RecFM实现了科学系统的高保真一到几步（2-4步）动态生成，性能与最先进的多步求解器相当。 RecFM为实时科学仿真提供了一种可扩展且高效的解决方案，使其能够在更少的步骤内实现高保真动态生成，这对需要兼顾准确性和计算效率的AI应用具有重要价值。

## 19.[Anticipate and Learn: Unleashing Idle-Time Compute in Proactive Agents](https://arxiv.org/pdf/2605.25971)
summary:**主动式代理, 空闲计算, 未来状态预测, 知识获取, ProActEval**  ProAct是一款利用空闲计算时间，通过分析对话历史和持久内存来预测和满足即将到来的用户需求的主动式代理架构，它能显著加速任务完成、减少用户投入并降低幻觉率，同时在反射准确性方面达到最先进水平。  该研究旨在解决当前AI代理在用户交互之间浪费大量空闲时间、无法主动为未来用户需求做准备的被动性问题。  ProAct架构通过未来状态预测模块持续预测用户潜在未来需求，并整合对话历史与持久内存（包含用户画像、摘要、存储事实和未解决的记忆空白）。随后，空闲时间获取模块根据用户相关性、知识差距、增量价值和及时性评估这些预测需求，并有选择地分配背景计算资源以检索和验证支持性证据、生成知识工件并提交到内存。  经验结果表明，在ProActEval基准测试中，ProAct相较于被动基线减少了14.8%的所需轮次，降低了11.7%的用户投入，并将幻觉率减少了28.1%。此外，MemBench评估证实ProAct实现了最先进的反射准确性。  对于AI从业者而言，该研究揭示了通过结构化利用代理空闲计算时间进行预测和知识获取，可以构建更高效、用户友好且低错误率的主动式AI系统，从而优化资源利用并提升多轮交互的用户体验。
