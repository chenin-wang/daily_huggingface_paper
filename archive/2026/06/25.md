## 0.[Qwen-AgentWorld: Language World Models for General Agents](https://arxiv.org/pdf/2606.24597)
summary:**世界模型**、**通用智能体**、**环境仿真**、**语言模型**、**AgentWorldBench**  本研究引入Qwen-AgentWorld系列语言世界模型，通过三阶段训练管线，模拟七个领域的智能体环境动态，旨在推动通用智能体在可扩展可控模拟及作为智能体基础模型方面取得性能提升。  该论文旨在探究基于语言模型的世界建模如何进一步拓展通用智能体的边界，重点在于构建用于智能体环境仿真的基础模型，并探索世界建模增强通用智能体的两种互补范式。  Qwen-AgentWorld（包括35B-A3B和397B-A17B两种规模）利用超过1000万条真实环境中七个领域的交互轨迹进行训练。训练通过三阶段管线进行：CPT阶段注入通用世界建模能力，SFT阶段激活下一状态预测推理，RL阶段通过混合评分和规则奖励框架提升仿真保真度。模型通过AgentWorldBench基准进行评估，该基准由5个前沿模型在9个既定基准上的真实交互构建，并通过地面真实评分在5个维度上评估世界建模质量。  经验结果表明，Qwen-AgentWorld显著优于现有前沿模型，其中Qwen-AgentWorld-397B-A17B在总平均分上达到58.8，超越GPT-5.4的58.2。作为解耦的环境模拟器，Qwen-AgentWorld支持数千个真实世界环境的可扩展可控模拟，其收益超越了仅在真实环境中训练的收益。  Qwen-AgentWorld的发现为AI从业者提供了通过语言世界模型构建更强大通用智能体的新途径。其可扩展和可控的环境模拟能力，允许在计算受限或风险高昂的场景下进行高效的智能体训练，从而提高智能体的鲁棒性和泛化能力。

## 1.[NatureBench: Can Coding Agents Match the Published SOTA of Nature-Family Papers?](https://arxiv.org/pdf/2606.24530)
summary:**NatureBench, NatureGym, AI编程智能体, 科学发现, SOTA** 本文介绍了NatureBench，一个包含90项任务的跨学科基准测试，旨在评估AI编程智能体能否在真实科学问题上超越复现，实现发现，该基准基于NatureGym自动化管道构建，解决了现有基准中的环境碎片化问题。 该研究旨在评估AI编程智能体是否能够在真实科学问题上超越既有方法，达到甚至超越Nature-家族论文中报告的SOTA表现，从而实现科学发现。 核心方法是NatureGym，一个自动化管道，它将已发表论文转化为标准化的、每任务容器化环境，提供任务简报、数据集、隐藏真实测试集和自动化评估器，并采用信息防火墙隔离原始方法，迫使智能体自主发现解决方案。 在对十种前沿智能体配置进行严格的禁用网络搜索评估后，发现最强的模型在g>0.1标准下仅在17.8%的任务上超越了SOTA。智能体的成功主要通过方法论转换，将科学任务转化为熟悉的监督预测问题，而非真正的科学发明；失败则主要归因于错误的方法选择和计算预算不足。 这项研究对AI工程师和数据科学家揭示了当前AI编程智能体在科学发现方面的局限性，其主要挑战在于方法选择和执行深度而非任务理解，提示未来AI工具应侧重于提升方法创新能力和解决复杂计算约束下的深度探索，以实现真正的科学突破。

## 2.[MobileForge: Annotation-Free Adaptation for Mobile GUI Agents with Hierarchical Feedback-Guided Policy Optimization](https://arxiv.org/pdf/2606.19930)
summary:**移动GUI代理, 无标注自适应, 分层反馈, 策略优化, GRPO** MobileForge是一个用于移动GUI代理的无标注自适应系统，通过MobileGym将任务生成和回放评估与真实移动应用交互相结合，并利用分层反馈引导的策略优化（HiFPO）将轨迹结果、步骤级反馈和修正提示转化为上下文感知的GRPO更新，显著提高了移动GUI代理在真实应用中的性能。  该研究旨在解决MLLM-based移动GUI代理在适应真实目标应用时，因应用数量多、更新频繁且难以通过人工任务、演示或奖励标签覆盖而导致的昂贵成本问题，同时克服现有无标注GUI学习中缺乏统一的自适应基础和策略优化依赖孤立回放及粗糙奖励的局限性。  MobileForge系统由两部分组成：MobileGym和分层反馈引导的策略优化（HiFPO）。MobileGym负责在真实移动应用交互中生成任务并评估回放，而HiFPO则将轨迹结果、步骤级过程反馈和修正提示转化为上下文感知的步骤级GRPO更新，从而优化策略。  MobileForge仅使用自动生成的无标注自适应数据，将Qwen3-VL-8B在AndroidWorld上的Pass@3性能提升至67.2%，接近闭源GUI专用模型GUI-Owl-1.5-8B的69.0%。经MobileForge自适应后的ForgeOwl-8B在AndroidWorld上Pass@3达到77.6%，并在域外MobileWorld GUI-only数据集上取得41.0%的成功率，成为评估中最强的开放数据移动GUI代理。  MobileForge为AI从业者提供了一种高效的无标注自适应框架，能够降低开发和部署移动GUI代理的成本，尤其是在目标应用频繁更新或数量庞大的场景下。通过分层反馈和上下文感知的GRPO优化，该方法显著提升了代理在复杂真实环境中的鲁棒性和泛化能力，为构建更智能、更独立的AI代理奠定了基础。

## 3.[Escaping the Self-Confirmation Trap: An Execute-Distill-Verify Paradigm for Agentic Experience Learning](https://arxiv.org/pdf/2606.24428)
summary:**代理经验学习, 自我确认陷阱, EDV框架, 多智能体协作, 可靠的自我进化** 本文提出EDV（执行-提炼-验证）框架，通过解耦执行、提炼和验证阶段，将其转化为协作式经验构建过程，以解决大型语言模型代理经验学习中单一智能体循环容易陷入“自我确认陷阱”的问题，从而实现代理的可靠自我进化。 该研究旨在解决大型语言模型代理经验学习中不可靠性问题，特别是单一代理循环导致“自我确认陷阱”并积累错误的问题。 EDV框架包含三个阶段：执行阶段，多个异构代理并行探索任务空间以生成多样化候选轨迹；提炼阶段，指定的第三方提炼代理对比分析这些轨迹以生成候选经验，减少执行者中心的总结偏差；验证阶段，执行组通过共识机制共同验证候选经验，只有通过严格验证的经验才被写入共享或私有记忆。 在t²-bench、Mind2Web和MMTB等长周期基准测试上的评估结果显示，EDV持续优于强大的基线模型。 对于AI从业者而言，这些发现强调了通过EDV等可靠协作过程构建的记忆质量对于代理的鲁棒自我进化比记忆数量更为关键，为构建更可靠的自我改进代理提供了实用范式。

## 4.[MemGUI-Agent: An End-to-End Long-Horizon Mobile GUI Agent with Proactive Context Management](https://arxiv.org/pdf/2606.19926)
summary:**MemGUI-Agent**, **移动GUI智能体**, **上下文管理**, **ConAct**, **MemGUI-3K** MemGUI-Agent 提出了一种端到端的长周期移动 GUI 智能体，通过主动上下文管理和 Context-as-Action (ConAct) 范式，在长周期任务上取得了卓越性能并具备领域外泛化能力。该研究旨在解决基于多模态大语言模型 (MLLM) 的移动 GUI 智能体在长周期任务中因 ReAct 风格的被动上下文管理导致的提示爆炸和关键信息稀释问题。MemGUI-Agent 基于 Context-as-Action (ConAct) 构建，将上下文管理作为与 UI 动作同等的首要动作，通过维护折叠动作历史、折叠 UI 状态和最新步骤记录三个结构化上下文字段，紧凑地保存关键 UI 事实。为使主动上下文管理可学习，构建了包含 2,956 条轨迹及完整 ConAct 注释的 MemGUI-3K 数据集。在 MemGUI-3K 数据集上训练的 8B 模型 MemGUI-8B-SFT，在 MemGUI-Bench 上实现了最佳的开源 8B 性能，并泛化到域外 MobileWorld 基准测试。该工作为开发能够处理复杂、多步骤任务的移动 GUI 智能体的 AI/ML/软件工程师和数据科学家提供了更可靠、更具扩展性的方法，有助于降低上下文过载并改善事实保留。

## 5.[OpenThoughts-Agent: Data Recipes for Agentic Models](https://arxiv.org/pdf/2606.24855)
summary:**智能体语言模型, 训练数据整理, 消融实验, 泛化** OpenThoughts-Agent项目通过开发一个完全开放的智能体模型训练数据整理管道，旨在解决现有智能体模型训练数据策展方法无法泛化到多样化任务的问题，并验证其数据在提升智能体模型性能及数据扩展性方面的核心价值。 该研究旨在解决现有智能体语言模型训练数据策展方法难以支持模型在多样化智能体任务中实现泛化的问题。 该项目开发了一个完全开放的智能体模型数据整理管道，并通过超过100次受控消融实验系统地探究了数据整理管道的每个阶段，特别是任务来源和多样性的重要性；随后，研究团队利用该管道生成了一个包含10万个训练示例的数据集，并在此数据集上对Qwen3-32B模型进行了微调。 研究结果显示，在所构建的10万示例训练集上微调的Qwen3-32B模型在七个智能体基准测试上的平均准确率达到44.8%，相较于当前最强的开放数据智能体模型Nemotron-Terminal-32B（40.9%）提升了3.9个百分点；此外，该训练数据在计算受控的对比中，在所有训练集规模下均展现出强大的扩展特性，优于其他开放数据集。 该研究为AI从业者提供了关于如何为通用智能体策展训练数据的深入见解和实用管道，特别强调了任务来源和多样性的重要性，并公开了训练集、数据管道、实验数据和模型，从而支持未来智能体模型训练的开放研究和技术发展。

## 8.[Critique of Agent Model](https://arxiv.org/pdf/2606.23991)

## 9.[FLAT: Feedforward Latent Triangle Splatting for Geometrically Accurate Scene Generation](https://arxiv.org/pdf/2606.24876)
summary:**前馈潜在三角形溅射**, **几何精确场景生成**, **视频扩散模型**, **表面对齐基元**, **可微分渲染**  FLAT首次展示了如何将视频扩散模型的压缩潜在表示直接一次性映射到显式表面基元（三角形splats），以实现几何精确且视觉质量具有竞争力的场景生成。  该研究旨在解决现有前馈潜在场景解码器输出的体积3D高斯缺乏明确表面定义的问题，并探讨压缩视频扩散潜在表示能否直接一次性映射到显式表面基元。  FLAT通过引入两大关键技术实现了这一目标：一是针对三角形回归的射线中心旋转参数化，以避免退化三角形和不稳定的世界空间方向；二是采用一种新颖的乘积窗口函数，通过在可微分三角形渲染期间改善梯度流，解决了预测平面基元的高敏感性挑战。  在标准基准测试中，FLAT在几何精度方面显著优于3D高斯解码，同时保持了与最先进前馈基线相当的视觉质量，并可通过轻量级测试时间优化将预测的三角形转换为完全不透明、游戏引擎就绪的实时渲染表示。  该研究为AI从业者提供了直接从视频扩散潜在空间生成高保真、几何精确3D场景的有效方法，通过使用显式表面基元，显著提升了生成结果与传统图形管线及游戏引擎的兼容性。

## 10.[Semantic Browsing: Controllable Diversity for Image Generation](https://arxiv.org/pdf/2606.23679)
summary:**语义浏览**, **图像生成**, **可控多样性**, **文本到图像模型**, **代理工作流** 本文针对现代文本到图像模型在生成图像时多样性不足的问题，提出了一种名为“语义浏览”的可控多样性方法，使用户能够通过系统性地遍历有意义且可解释的变体维度来探索结构化的图像图库。  该研究旨在解决文本到图像模型生成的样本多样性受限、倾向于单一视觉解释的问题，并实现对生成样本多样性结构化的控制。  核心方法是通过在文本层面而非图像模型内部引入多样性。它将生成过程形式化为构建结构化场景空间内的分层解释树，并利用视觉语言模型（VLM）处理丰富的文本表示和完整的场景上下文。一个代理工作流是关键，该工作流将用户提示扩展为结构化的JSON格式，并通过上下文分析师、头脑风暴者、决策者和评论者等代理的协作，迭代地扩展和细化此树，以确保结构化变体与原始提示保持一致，并产生可理解的语义决策。  实验结果表明，该方法在多样性方面优于所有竞争基线，实现了最高的Vendi分数（3.34）和最低的DINO相似度（0.61），同时在保持可比的审美分数（6.52）的情况下，显著扩展了语义覆盖范围。  对于人工智能从业者而言，该研究提供了一种可控且可解释的图像生成多样性探索框架，通过结构化的语义决策而非随机变化来生成图像，极大地提升了文本到图像模型在创意探索和应用场景中的实用性和效率。

## 11.[DREAM: Dense Retrieval Embeddings via Autoregressive Modeling](https://arxiv.org/pdf/2606.24667)
summary:**稠密检索, 自回归下一词预测, 大型语言模型, 注意力机制**  本文提出DREAM，一种稠密检索嵌入模型训练方法，通过将检索器生成的查询-文档相似度分数注入冻结大型语言模型（LLM）的选定注意力头中，利用自回归下一词预测目标对检索器进行监督训练。本文旨在解决传统稠密检索器训练中对昂贵且难以获取的标注正负文档对的依赖，核心目标是探究大型语言模型的自回归下一词预测目标能否有效监督稠密检索器的训练。DREAM方法将检索器生成的查询-文档相似度分数注入到冻结大型语言模型的选定注意力头中，在训练期间，这些分数决定了LLM在预测目标输出时每个候选文档获得的注意力权重，由此产生的预测损失通过注意力机制为检索器训练提供梯度。在BEIR和RTEB检索基准上，使用0.5B至3B参数范围的嵌入骨干模型进行评估，DREAM在不同模型规模下始终优于现有基线。DREAM提供了一种通过自回归建模训练稠密检索器的有前景方法，这对于AI从业者而言，意味着能够克服传统对比学习方法对昂贵且难以获取的标注数据对的依赖，从而更高效地开发和部署稠密检索系统。

## 12.[VeriEvol: Scaling Multimodal Mathematical Reasoning via Verifiable Evol-Instruct](https://arxiv.org/pdf/2606.23543)
summary:**多模态数学推理**, **可验证数据构建**, **Evol-Instruct**, **强化学习**, **HTV-Agent**  VeriEvol提出了一种可验证的数据构建迭代框架，通过类型感知的进化模块扩展问题难度，并利用HTV-Agent验证器确保答案可靠性，从而解决了多模态视觉数学推理中强化学习数据质量和奖励标签可靠性的规模化挑战。  该研究旨在解决视觉数学推理中强化学习扩展时奖励标签可靠性不足的问题，即现有数据流水线在数据量增长时未能确保答案的可靠性。  VeriEvol框架解耦了提示难度和答案可靠性两个维度。提示难度通过类型感知进化模块实现，该模块利用路由特定进化算子将低难度图像-问题种子重写为更难的、图像锚定的提示。答案可靠性通过HTV-Agent验证器强制执行，该验证器仅在多源反驳证据未能证伪后才接受答案，从而确保离线假设检验的可靠性。  在五项视觉数学基准测试套件上，将进化的SFT数据从10K扩展到250K样本，平均准确率从35.42提高到54.73。此外，VeriEvol相较于未进化的RL基线，累计提高了3.88，其中进化提示贡献1.82，HTV-Agent验证器贡献2.06。  VeriEvol为AI从业者提供了一种可扩展且可审计的高质量多模态数学推理训练数据构建方法，通过解耦提示进化和答案验证，确保了在数据量增长时的奖励标签可靠性，并支持现有强化学习框架，提升了模型性能和数据透明度。
