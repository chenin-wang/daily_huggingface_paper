

# Papers for 2025-10-30

## 0.[InteractComp: Evaluating Search Agents With Ambiguous Queries](https://arxiv.org/pdf/2510.24668)
summary:**搜索代理**, **模糊查询**, **交互式消歧**, **基准测试** 本文提出了一个名为InteractComp的新基准，它通过一种“目标-干扰项”方法构建了只能通过交互解决的模糊查询，旨在评估搜索代理识别并主动解决查询模糊性的核心能力。 该研究旨在解决当前搜索代理研究中的一个关键问题：如何系统性地评估代理在面对不完整或模糊的用户查询时，主动通过交互来澄清意图的能力，而现有基准普遍假设查询是完整明确的。 其核心方法是构建一个包含210个专家策划问题的InteractComp基准。该方法通过配对一个知名度较低的目标实体和一个流行的干扰项实体，并仅使用它们的共享属性来构造问题，从而创造出真实存在的模糊性，这种模糊性只有通过交互获取被隐藏的独特属性信息才能被解决。 对17个模型的评估显示，最佳模型在完整交互环境下的准确率仅为13.73%，但当为其提供完整上下文后，准确率飙升至71.50%，这揭示了模型存在系统性的过度自信而非推理能力缺陷。 对于AI从业者而言，这项工作揭示了当前代理开发中的一个关键盲点，即搜索能力的提升并未转化为交互能力的进步。该基准不仅是一个评估工具，其清晰的奖励信号也使其成为一个宝贵的训练资源，可用于通过强化学习等方法来开发更具不确定性感知和主动交互能力的智能代理。

## 1.[Tongyi DeepResearch Technical Report](https://arxiv.org/pdf/2510.24701)
summary:**核心关键词**：智能体大语言模型, 深度研究, 端到端训练, 数据合成流水线, 智能体中训  **一句话核心摘要**：该论文介绍了一款名为“通义DeepResearch”的智能体大语言模型，它通过一个结合了智能体中训与后训练的端到端训练框架，并由全自动数据合成流水线支持，旨在为长时程、深度信息检索的研究任务提供可扩展的自主推理与信息搜寻能力，并在多个基准测试中取得了当前最佳性能。  **主要研究问题或目标**：该研究旨在解决在深度研究代理领域，缺乏一个系统化、可完全开源的方法论和模型的痛点，其目标是开发一个能够自主执行规划、搜索、推理和信息综合等复杂长时程研究任务的开源智能体大语言模型。  **关键方法论**：模型采用了一个端到端的训练范式，首先通过“智能体持续预训练”（Agentic CPT）作为中训阶段，为模型注入智能体行为的归纳偏置；随后进入后训练阶段，包含用于冷启动的监督微调（SFT）和用于策略优化的智能体强化学习（RL）。整个流程的核心驱动力是一个全自动、可扩展的数据合成流水线，它无需人工标注即可生成高质量、多样化的智能体轨迹数据，并为不同训练阶段构建了定制化的交互环境（包括先验世界、模拟环境和真实世界）以确保训练的稳定性和一致性。  **主要成果**：实验结果表明，通义DeepResearch模型（总参数305亿，每token激活33亿）在多个智能体深度研究基准测试中表现卓越，全面超越了现有强基线模型。例如，在FRAMES基准测试中取得了90.6%的准确率，在Humanity's Last Exam上达到32.9%，在GAIA上达到70.9%，均展示了其在英文和中文任务上的强大泛化能力和顶尖性能。  **对AI从业者的主要启示**：此项工作为AI从业者提供了一套完整的、可复现的开源解决方案，用于构建高性能的自主研究智能体。其关键价值在于展示了如何通过全自动数据合成流水线有效替代昂贵的人工标注，解决了智能体训练中数据稀缺的核心瓶颈，并提供了一个从模型、框架到完整解决方案的开源基础，使开发者能够基于此构建和定制满足特定需求的自动化研究工具。

## 2.[AgentFold: Long-Horizon Web Agents with Proactive Context Management](https://arxiv.org/pdf/2510.24699)
summary:**核心关键词**：长程任务, 上下文管理, 多尺度折叠, 网页智能体  **一句话核心摘要**：该论文介绍了一种名为AgentFold的新型网页智能体范式，它通过一种主动、多尺度的“折叠”操作来动态管理上下文，解决了传统智能体在长程任务中面临的上下文饱和与关键信息丢失的根本性权衡问题。  **主要研究问题或目标**：本研究旨在解决长程网页智能体中的一个核心技术挑战：如何在不导致上下文饱和或不可逆地丢失关键细节的前提下，有效管理和压缩智能体的交互历史。  **关键方法论**：该研究提出了AgentFold方法，将智能体上下文视为一个动态工作空间，并在每个交互步骤中学习执行一个“折叠”操作；该操作具备两种模式：一是“粒度压缩”，用以保留单个步骤的关键细节，二是“深度整合”，用以抽象和总结整个多步子任务，从而在不同尺度上主动地管理历史轨迹。  **主要结果**：实验结果表明，仅通过监督微调，30B参数的AgentFold模型在BrowseComp基准测试上取得了36.2%的成绩，其性能不仅超越了规模远大于自身的开源模型（如671B的DeepSeek-V3.1），也超越了部分主流的专有智能体。  **对AI从业者的主要启示**：对于AI工程师和研究者而言，AgentFold范式提供了一种构建高效、可扩展长程智能体的实用路径；其主动上下文管理机制表明，通过精巧的上下文工程，较小参数规模的模型也能在复杂的长程任务上达到甚至超越超大模型的性能，为开发资源受限但性能要求高的智能体应用提供了新的思路。

## 3.[RoboOmni: Proactive Robot Manipulation in Omni-modal Context](https://arxiv.org/pdf/2510.23763)
summary:核心关键词：**主动机器人操控, 全模态上下文, 意图识别, 端到端框架**  一句话核心摘要：该研究提出了一个名为RoboOmni的端到端全模态大语言模型框架，该框架通过融合口语对话、环境音和视觉线索等跨模态上下文信息，解决了机器人仅依赖显式指令进行操控的局限性，实现了主动的用户意图识别与交互式操作。  主要研究问题或目标：本研究旨在解决当前机器人操控模型过度依赖显式文本指令的问题，使其能够像人类一样，通过综合分析口语对话、环境声音和视觉场景等多种模态的上下文信息，主动推断并执行用户的潜在意图。  关键方法论：论文提出了一个名为RoboOmni的“感知-思考-对话-执行”（Perceiver-Thinker-Talker-Executor）统一框架。该框架基于一个端到端的全模态大语言模型，通过时空融合的方式处理听觉和视觉信号进行意图识别，并将意图识别、交互确认和动作执行整合在单一模型中。为解决训练数据缺失问题，研究团队还构建了包含14万个片段的OmniAction数据集。  主要结果：实验结果表明，RoboOmni在模拟和真实世界环境中均显著优于基于文本和自动语音识别（ASR）的基线模型。在跨模态上下文指令的综合评估中，RoboOmni的总体任务成功率达到了85.6%，远超最强的基线模型（25.9%），证明了其在成功率、意图识别准确性和主动辅助能力上的优越性。  对AI从业者的主要启示：该研究为AI从业者提供了一个构建更自然、更主动的人机交互系统的范例，证明了端到端全模态模型在处理原始音频和视觉信号以理解隐式意图方面的巨大潜力。从业者可以借鉴其框架设计，利用原始多模态数据流代替分离的、基于文本的流程（如ASR转录），从而开发出在复杂现实世界场景中响应更灵敏、交互更智能的具身智能体。

## 4.[Game-TARS: Pretrained Foundation Models for Scalable Generalist Multimodal Game Agents](https://arxiv.org/pdf/2510.23691)
summary:**通用游戏智能体**，**统一动作空间**，**大规模预训练**，**稀疏思考**  该研究提出了通用游戏智能体Game-TARS，它通过采用一个锚定于人类原生键鼠输入的统一、可扩展动作空间，并在超过500B通证的多样化数据上进行大规模预训练，在多个基准测试中实现了超越现有SOTA模型的卓越性能。  本研究旨在解决传统智能体因依赖特定于环境的API或GUI动作空间而导致的可扩展性差和泛化能力弱的核心问题。  其核心方法是构建一个基于原生键鼠输入的统一动作空间，从而实现跨异构领域的大规模持续预训练；关键技术包括在超过500B通证的多模态数据上进行训练，并采用衰减连续损失函数（decaying continual loss）以减少因果混淆，以及一种高效的稀疏思考（Sparse-Thinking）策略来平衡推理深度与计算成本。  实验结果显示，Game-TARS在开放世界游戏Minecraft任务上的成功率达到了先前最先进模型的大约2倍，并且在第一人称射击（FPS）游戏基准测试中胜过了GPT-5、Gemini-2.5-Pro和Claude-4-Sonnet。  对于AI从业者而言，这项工作的首要启示是，一个简单、可扩展的动作表征（如原生键鼠输入）与大规模数据预训练相结合，是构建具备广泛问题解决能力的通用智能体的有效路径，为开发能跨越不同游戏和应用、无需为每个环境定制接口的通用智能体提供了新的范式和有力证据。

## 5.[Uniform Discrete Diffusion with Metric Path for Video Generation](https://arxiv.org/pdf/2510.24717)
summary:**离散扩散, 度量路径, 视频生成, 迭代精炼** 该研究提出了一种名为URSA的统一离散扩散框架，它将视频生成任务构建为离散时空令牌的迭代式全局精炼过程，通过引入线性化度量路径和分辨率相关的步长时间移位机制，解决了现有离散方法中的误差累积和长上下文不一致问题，从而在可扩展视频生成方面弥合了与连续方法的性能差距。 本研究旨在解决离散视频生成方法因误差累积和长上下文不一致性而落后于连续空间方法的核心问题，其目标是开发一个能够高效扩展至高分辨率和长时视频生成任务的离散生成框架。 该论文的核心方法URSA是一个基于离散流匹配的统一扩散框架，它将视频生成建模为从类别噪声出发、对全局时空令牌进行迭代精炼的过程。其关键技术包括：1）设计了一个线性化度量路径，该路径基于令牌嵌入距离来引导概率演化，以实现对扰动过程的精确控制；2）引入了分辨率相关的步长时间移位机制，根据序列长度动态调整扰动强度；3）采用异步时间步调度策略，为视频中的每一帧独立采样噪声水平，从而在单一模型中统一了多种生成任务。 实验结果表明，URSA在多个基准测试中显著优于现有的离散生成方法，并达到了与先进连续扩散模型相当的性能。具体而言，在VBench文本到视频生成基准上，URSA模型取得了82.4分的总分，展现了其在生成质量和语义对齐方面的强大竞争力。 对于AI从业者而言，本研究最重要的启示是，通过在离散令牌空间中采用迭代式全局精炼范式，可以有效克服传统离散生成模型（如自回归模型）的局限性，在实现与连续扩散模型相媲美的高质量视频生成的同时，还可能减少推理步骤。其提出的异步时间步调度策略为构建能够处理文本到视频、视频插值等多任务的统一生成模型提供了有效途径，简化了复杂视频应用系统的开发和部署。

## 6.[From Spatial to Actions: Grounding Vision-Language-Action Model in Spatial Foundation Priors](https://arxiv.org/pdf/2510.17439)
summary:**核心关键词**： **视觉-语言-行动(VLA)模型**，**空间基础先验**，**空间增强行动头**，**模态可迁移性**  **1-Sentence Core Summary**： 该研究提出了一种名为FALCON的新范式，通过将空间基础模型提供的丰富3D空间令牌注入到一个空间增强行动头中，旨在解决现有VLA模型因依赖2D编码器而产生的空间推理鸿沟，从而提升其在3D真实世界中的泛化与适应能力。  **Main Research Question or Objective**： 本文旨在解决现有视觉-语言-行动(VLA)模型在3D真实世界中缺乏空间推理能力、模态可迁移性差以及注入3D信息时视觉-语言对齐被破坏的问题。  **Key Methodology**： 该研究的核心方法是FALCON，其利用空间基础模型从单一RGB图像中提取丰富的3D几何先验作为空间令牌。该模型包含一个“具身空间模型”(Embodied Spatial Model)，可选择性地融合深度或位姿信息以增强保真度。为保留语言推理能力，这些空间令牌被直接注入到一个新颖的“空间增强行动头”(Spatial-Enhanced Action Head)中用于生成动作，而非与视觉语言主干网络拼接，从而避免了破坏预训练的对齐。  **Primary Results**： 实验结果表明，FALCON在三个仿真基准和十一个真实世界任务中均达到最优水平。例如，在包含九个任务套件的真实世界基础任务评估中，FALCON取得了70.0%的平均成功率，相较于先进的SpatialVLA方法（44.4%）提升了25.6%。  **Principal Implication for AI Practitioners**： 对于AI从业者而言，该研究提供了一个在VLA模型中高效集成3D空间感知的实用范式。其核心价值在于，通过将空间信息注入行动头而非VLM主干，既能显著增强机器人的几何推理能力，又可保护VLM强大的语义理解和泛化能力不被破坏，同时支持从纯RGB到多模态输入的灵活切换，降低了对特定传感器的依赖，对开发在复杂真实环境中稳定运行的通用机器人系统具有重要指导意义。

## 7.[Repurposing Synthetic Data for Fine-grained Search Agent Supervision](https://arxiv.org/pdf/2510.24694)
summary:**核心关键词**：搜索智能体, 实体感知, 稠密奖励, GRPO  **一句话核心摘要**：该研究提出了一种名为实体感知组相对策略优化（E-GRPO）的框架，通过利用合成数据中被丢弃的实体信息构建稠密奖励函数，从而更有效地训练用于处理知识密集型任务的搜索智能体。  **主要研究问题或目标**：本研究旨在解决现有搜索智能体训练方法（如GRPO）中存在的奖励稀疏问题，即这些方法仅依赖最终结果的对错，无法区分包含部分正确推理的“准失败样本”与完全失败的样本，导致有价值的学习信号被浪费。  **关键方法论**：该研究的核心方法是提出实体感知组相对策略优化（E-GRPO），它重新利用了合成数据生成过程中被丢弃的真实实体；该框架设计了一个稠密的、与实体相关的奖励函数，为回答错误的样本根据其推理过程中识别出的正确实体的匹配率（entity match rate）赋予部分奖励，从而为模型提供更细粒度的学习信号。  **主要成果**：实验结果表明，E-GRPO在多个问答和深度研究基准上显著且稳定地优于GRPO基线；例如，在本地知识库环境的标准QA基准测试中，E-GRPO模型（Local-7B-E-GRPO）的平均Pass@1得分达到64.2，比GRPO基线高出2.8个百分点，同时还能学习到使用更少工具调用的高效推理策略。  **对AI从业者的主要启示**：对于AI工程师和研究人员而言，这项工作的主要价值在于揭示了合成数据生成过程中的“副产品”（如实体信息）可以被重新利用为高质量的细粒度监督信号；这提供了一种无需额外标注成本、计算开销极小的方法，通过设计更稠密的奖励函数来解决强化学习中的奖励稀疏问题，从而更高效地对齐和优化自主智能体。

## 8.[OSWorld-MCP: Benchmarking MCP Tool Invocation In Computer-Use Agents](https://arxiv.org/pdf/2510.24563)

## 13.[Group Relative Attention Guidance for Image Editing](https://arxiv.org/pdf/2510.24657)
