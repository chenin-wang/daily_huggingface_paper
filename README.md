summary:**分层显式语言记忆**, **非马尔可夫操作**, **视觉-语言-动作 (VLA) 模型**, **事件触发更新** HeLM是一个分层视觉-语言-动作（VLA）框架，通过因式分解的事件检测和事件触发的记忆更新，以显式语言形式维护任务相关历史，解决了现有VLA模型在非马尔可夫环境中由于马尔可夫假设导致的内存密集型任务失败问题。 本研究旨在解决VLA模型在需要工作记忆的非马尔可夫操作任务中遇到的挑战，现有模型通常基于马尔可夫假设运行，无法有效处理任务相关历史。 HeLM通过一个分层VLA框架实现，其中高层策略（HLP）负责以显式语言形式维护任务相关历史并生成动作指令，低层策略（LLP）执行动作；记忆更新仅在检测到任务相关事件或指令改变时触发，并且语言记忆被组织成工作记忆和情节记忆字段。 在10项非马尔可夫真实世界任务中，HeLM将内部任务成功率提高了12.8个百分点，在组合泛化任务上实现了78%的子任务成功率，同时在长时程任务中相比关键帧基线减少高达4.5倍的内存并运行速度快2.5倍。 这意味着AI从业者可以利用HeLM开发更高效、可解释且能在长时程和复杂非马尔可夫环境中执行精细操作的机器人控制系统，从而克服现有VLA模型的关键局限性。

## 20.[Hard Sample-Conditioned Decorrelated Attention for Robust Face Recognition](https://arxiv.org/pdf/2610.41789)
summary:**ViT**, **多头注意力**, **困难样本**, **解耦**, **人脸识别** 本文提出ViT-HarDis，一种基于困难样本条件化的注意力头解耦框架，通过自适应增强困难样本的注意力头解耦以提升ViT在人脸识别任务中的鲁棒性与泛化能力。  本研究旨在解决Vision Transformers (ViTs) 中多头注意力模式冗余且未能充分利用模型容量的问题，尤其是在人脸识别任务中，需要通过自适应的注意力头专业化来优化和泛化模型，特别是针对困难样本。  ViT-HarDis的核心方法是根据样本难度来条件化注意力头解耦，对与负类别中心余弦相似度高的困难样本施加强化解耦，以强制在身份模糊性最高处进行注意力头专业化。此外，该方法发现仅对Transformer的最终层应用解耦比对整个网络进行正则化效果更好。  实验结果表明，ViT-HarDis在IJB-B、IJB-C和TinyFace Rank-1等基准测试上超越了基线ViT和均匀解耦方法，并在WebFace4M训练时，在这些基准测试上实现了ViT类方法的SOTA结果。  对于AI从业者，ViT-HarDis提供了一种无需修改ViT架构或增加推理成本即可提升人脸识别性能的有效策略，通过将注意力头专业化与样本难度自适应结合，尤其有助于解决困难样本的身份模糊性，从而提高模型的鉴别力和泛化能力。
