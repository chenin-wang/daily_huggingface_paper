summary:**多语言基准**, **类型化决策路由**, **语码混合**, **LLM生成标签**, **性能排行榜** PolyRoute发布了一个多语言和语码混合的类型化决策路由基准，包含LLM生成的数据、基线和排行榜，旨在提供一个固定标准来衡量类型化决策编码器在英语之外语言上的性能。该研究旨在解决类型化决策编码器在英语之外的语言中，其行为缺乏固定衡量标准的问题。PolyRoute基准包含322条12种语言的母语支持消息、156条语码混合或罗马化的消息以及967条可选的母语训练数据，并采用三向部门路由决策协议，标签由Qwen3.8-27B通过盲法二次标注生成，并经独立模型gemma4-31b验证，其测试项一致性达97.2%。排行榜显示，最佳微调模型的准确率达到96.6%，而TF-IDF结合逻辑回归的基线表现为91.9%；在语码混合文本上，英语根模型的准确率为85%，名义上领先于多语言检查点（79%），且该基准在322个测试项上的统计可区分差异约为4个点。对于AI从业者而言，PolyRoute提供了一个标准化、多语言的测试平台，可用于评估和比较不同语言模型或微调策略在实际路由任务中的性能，尤其是在非英语及语码混合场景下，帮助识别模型的语言能力差距。
