summary:**DecisionRank**, **决策模型**, **策略蒸馏**, **项目空间**, **重排序** DecisionRank 提出了一种通过项目空间策略蒸馏（OPD）训练的决策模型，旨在将生成式大语言模型的排序知识高效地迁移到决策模型中，从而避免自回归解码延迟并实现最先进的重排序性能。  论文旨在解决将生成式大型语言模型的排序知识有效迁移到决策模型（通过单次前向传递预测选择或分数）的挑战，特别是弥合教师模型（使用文档ID序列排名）与学生模型（使用首个token位置分数确定排名）之间的结构性差异，以避免自回归解码的推理延迟。  核心方法是引入DecisionRank，一个通过项目空间策略蒸馏（OPD）训练的决策重排序模型。具体来说，项目空间OPD通过将学生模型的文档分数排序来构建其rollout，形成一个排名序列。然后，一个生成式教师模型将该排名列表作为输入，提供条件反馈直接监督这些分数。此方法与离线排序监督相结合，共同优化学生模型的首个token分数。  DecisionRank 在TREC DL、BEIR和BRIGHT等通用及推理密集型检索基准上实现了最先进的性能。例如，在1.7B参数量下，DecisionRank在TREC DL19-23上超越了其27B生成式教师模型；在8B参数量下，它比其生成式列表式对等模型在TREC DL上快24.5倍，在BRIGHT上快16.7倍。  对于AI从业者而言，DecisionRank提供了一种将生成式大语言模型（LLM）的复杂排序能力蒸馏到高效决策模型中的有效途径，显著降低了推理延迟，使其更适用于需要快速响应的实际重排序应用，如搜索引擎和推荐系统，同时保持甚至超越教师模型的排序准确性。

## 21.[DR Pixel: Page-Native Deep Research with Vision-Language Models](https://arxiv.org/pdf/2611.03097)
summary:**DR Pixel**, **页面原生深度研究**, **视觉语言模型**, **反事实信用再加权**, **DRPixelBench** 本文介绍了**DR Pixel**，一个利用**视觉语言模型**进行**页面原生深度研究**的开源端到端多模态智能体，该智能体通过直接检索和推理渲染的文档页面图像，并在**DRPixelBench**基准上进行评估，同时引入**反事实信用再加权**训练方法以提高其效率和准确性，从而实现更有效和高效的复杂文档深度研究。  该研究旨在解决现有深度研究（DR）智能体将复杂文档（如科学论文）简化为OCR提取文本所带来的信息丢失和错误传播问题，核心目标是探讨视觉语言模型（VLMs）是否能够实现页面原生的深度研究，即直接检索和推理渲染的文档页面图像。  核心方法是**DR Pixel**智能体，它摒弃了传统的OCR-then-retrieve（OCR后检索）流程，转而将渲染的文档页面图像作为唯一的检索和推理单元。通过视觉语言模型直接处理页面图像，避免了因文本线性化造成的视觉结构丢失和OCR错误。为评估此设置，研究构建了**DRPixelBench**基准，并引入**反事实信用再加权**训练方法，该方法通过量化每个推理和行动步骤对最终答案的反事实贡献来分配精细的信用，以优化智能体轨迹中的冗余或失败尝试。  实验结果显示，未经训练的**DR Pixel**在**DRPixelBench**上表现优于GPT-5.4、Gemini-3.5-Flash和Qwen3.6-27B等OCR基线模型，同时所需的工具调用次数更少。经过训练后，其检索召回率提高了约15个百分点，最终准确率在**DRPixelBench**上提升了10多个百分点，并优于四个现有基准上的未经训练基线。在ViDoRe-V3数据集上，**DR Pixel**的性能仅比直接给定金页面的预言机低1.8个百分点。  对于AI从业者而言，这些结果表明传统的“OCR-后检索”管道并非必要且可能次优。直接对视觉文档页面进行检索和推理，能够使复杂的深度研究任务更有效、更高效，为开发处理多模态文档的智能体提供了新的方向。
