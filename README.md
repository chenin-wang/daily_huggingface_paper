## 21.[The Last Mile to the Real World: Agent-Native Primitives as Reusable Building Blocks for Solving Real-World Tasks](https://arxiv.org/pdf/2611.07461)
summary:**核心关键词**: **代理原生原语**, **HEELO**, **真实世界任务**, **LLM代理**, **执行器工程**  该研究通过引入配备常驻大型语言模型的代理原生原语和HEELO执行器工程框架，旨在弥合现有大型语言模型代理在真实世界任务“最后一公里”应用资源时的能力鸿沟，从而实现代理端到端处理任务的通用框架。  **主要研究问题或目标**: 该研究旨在解决代理如何端到端地处理真实世界任务的问题，特别是现有LLM代理在“最后一公里”（即从获取资源到应用资源）环节的性能不足。  **关键方法**: 研究通过引入“代理原生原语”（Agent-Native Primitives），每个原语配备常驻LLM以在上下文中应用资源。在此基础上，HEELO框架（Harness Engineering around Evolving Agent-Native Primitives for the Last Mile to Real-WOrld Tasks）从原语库中构建任务特定的执行器，通过任务特定图谱组合原语、依据环境证据验证结果并修订原语，以及验证后纳入新原语或改进原语。  **主要结果**: 在Terminal-Bench 4.0基准测试中，Dev-Primitives将Codex下的任务解决率从37.3%提高到55.5%。在heelo.dev平台的46项真实世界任务中，连接HEELO后，Claude Code和Codex的完成任务数均显著增加（从9项分别增至39和35项），且每完成一项任务的时间和成本显著降低（时间减少1.9倍和2.3倍，成本降低1.55倍）。  **对AI从业者的主要启示**: HEELO提供了一个统一的框架，通过Agent-Native Primitives将资源应用能力封装在原语内部，并支持原语的动态组合、证据驱动的修订和持续改进，这显著提高了LLM代理在处理复杂真实世界任务时的解决能力、效率和鲁棒性，为通用AI代理的实际落地提供了关键方法。
