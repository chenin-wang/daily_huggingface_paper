summary:**Prospective Hindsight (PH), 自校准强化学习, 预测-现实差距, 意外加权优势, 参数共享**  本文提出了前瞻性回溯（PH），一种自校准训练原则，通过利用智能体在反馈前的前瞻性预测与反馈后的回顾性评估之间的预测-现实差距作为信号，增强任何回顾性基础方法，从而同时提升任务性能和校准，并实现跨模型规模的一致性收益。  该研究旨在解决长周期智能体强化学习中，纯回顾性训练信号导致智能体在行动时的信念对梯度不可见，从而引发校准不足的问题。  PH通过引入一个源自智能体前瞻性预测（反馈前）与回顾性评估（反馈后）之间差距的信号，来增强任何回顾性基础方法。这种逐次推断的“意外”信号能够识别智能体自模型最不准确的样本，并通过停梯度意外加权优势放大其梯度贡献。由于前瞻性预测器与策略共享参数，两者共同演化，逐步将焦点转移到智能体剩余的盲点上，使校准作为优化的副产品而非额外目标自然涌现。  PH在单轮可验证任务和多轮个人智能体任务（在GRPO、在策略蒸馏及其组合下）中，均提升了任务性能和校准，并在不同模型规模上展示出一致的收益。值得注意的是，该方法成功应对了主导校准失误模式在不同任务机制间的结构性转变，即单轮任务中的过度自信失败和多轮任务中的自信不足成功。  PH为AI从业者提供了一种有效且通用的训练原则，能够在不引入额外校准目标的情况下，通过内部机制协同优化智能体的任务性能与自校准能力。这有助于构建更可靠的AI智能体，减少过度自信的失败，并简化训练流程，提升长周期智能体在复杂环境中的部署可行性。

## 20.[Evaluating LLM Creativity through Long-Tail Performance](https://arxiv.org/pdf/2610.12998)
summary:**LLM创造力评估**, **长尾性能**, **新颖性-质量乘积**, **n-gram缺失**, **q@Tail(α)**  该研究通过将大语言模型（LLM）创造力评估目标形式化为参考输入-输出分布的长尾性能，并基于新颖性-质量乘积公式和n-gram缺失作为新颖性代理，引入了q@Tail(α)诊断方法，旨在为LLM创造力评估和提升提供统一框架。  本研究旨在解决现有LLM创造力基准在任务和指标设计上的广泛差异性，提出并实证评估长尾性能作为衡量LLM共同创造力概念的共享目标。  核心方法是将创造力定义为参考输入-输出分布的长尾性能，该定义根植于新颖性-质量乘积公式，并使用预训练数据中n-gram的缺失作为新颖性代理。研究通过在15个基准和26个开源模型上进行实证评估，并引入了低成本的q@Tail(α)诊断工具，用于衡量现有基准长尾部分的平均任务质量。  结果显示，创造力基准比标准基准更集中在分布的长尾区域。此外，在创造力基准和标准基准上，模型在更高长尾子集中的排名与LM-Arena中的人类创造力判断更为一致。  该研究揭示，目前提升LLM创造力的方法在长尾性能上仍有显著改进空间。AI从业者应关注通过增强LLM在低概率（长尾）区域的性能来提升其创造力。
